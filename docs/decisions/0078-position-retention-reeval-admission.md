# 0078 — W3 队列③「位置保留（H-B）」开轮准入：旧臂的 null 已由原页自证为**弱操纵**，且该缺陷与网格无关 ⇒ 开轮（两臂，`scale` 为唯一因子）

- **日期**：2026-11-02
- **状态**：accepted
- **范围**：`docs/plans/0025-training-speed-observability-axis-reeval.md` §4.2 队列**第 3 条**
  （位置保留 H-B = `record:s3-typed-spatial-result`）；R3（H-C）已由 0077 **否决**，故轮次顺位到此条
- **依据**：0057（ADR 必须论证「不是同一族」）、`docs/R7_S3_TYPED_SPATIAL_RESULT.md` §7b/§8
  （原页自证的弱操纵）、`model/typed_evidence_r7.py:233-244`、决策 0074（R2 执行设计）的成本实测

## Context

**① 旧臂是什么、它的关闭依据是什么。** H-B 轮（2026-10-14）在 wide 129×129 上跑两臂：
B=`pooled`（对 P 个 patch 位置取**均匀均值**）、C=`spatial`（用**一个共享可学习的 `[dim]` query**
对 P 做 softmax 注意力）。C 恰多 `typed_evidence.position_query`（192 参数，`+0.13%` of 148800）。
唯一因子是**类型化证据在 patch 位置维上的聚合方式**。B→C 的 `interior_32` t2m Δrmse 五 lead
seed 均值 **+1.2e-7 / −1.3e-6 / −2.8e-6 / −6.5e-8 / +3.2e-6 K**（float32 噪声量级），
72 h 三 seed 不同号。按预声明出口关闭 H-B。

**② 但原页**自己**把这个 null 定性为「弱操纵下的 null」，且写在 §7b 与 §8 两处（本 ADR 的实证核心）。**
实测三 seed 的 `|position_query|` = **0.007393 / 0.012458 / 0.008398**，而同层投影
`projections.0.weight` 的模长 = **8.037 / 8.021 / 8.016**——**差三个数量级**。原页据此写明：
打分幅度约 `0.01 × O(1) / √192 ≈ 7e-4`，softmax 权重相对均匀分布只偏移约 **1e-3 相对量**，
「spatial 臂只在池化聚合附近一个很小的邻域里探索」，并明写
「**不能**据此说『保留空间结构对 48/72 h 无用』」。

⇒ **这一条与队列里其它三条不同**：它不是「null 但方向清晰」，也不是「未测」，
而是**本轮的操纵强度不够，原页已如实声明**。0057 要求 ADR 论证「不是同一族」——
这里能论证的是**更强的同族操纵**（把 query 的学习幅度提上去），而**这正是原页指出的必要下一步**，
不是换名重开。（区别：换名重开是「同一假设、同一操纵、改个名字再问」；
本条是「同一假设、**修正被自证为无效的操纵强度**后再问」，且旧页已把该修正写明为解锁条件。）

**③ 实测：该弱操纵缺陷与网格无关，新制度不会自动修复它——也不会自动恶化它。**
`_position_attention` 的打分是 `scores = (value @ position_query) / √dim`，softmax 定义在
**P 个 patch 位置上**。两实例的 P：

| 实例 | 模型输入 | patch 网格 | **P** |
| --- | ---: | ---: | ---: |
| 旧臂（H-B） | 129×129 | 65×65 | **4225** |
| 新制度（65×65 多年 store） | 65×65 | 33×33 | **1089** |

在**固定** `|q| ≈ 0.008` 下实测（每次 20 次抽样、`random.seed` 固定、`dim=192`）：
P=4225 时 `max|w − 1/P| × P ≈ 2.20e-3`，P=1089 时 ≈ **1.99e-3**——
**相对偏移与 P 几乎无关**（解析上：`w − 1/P ≈ (1/P)(s − mean s)`，故相对偏移 ≈ `std(s)`，
不随 P 变）。⇒ **换到 65×65 不会让 query 变得有效**：同一个 query 模长给出同一个相对偏移量级。
这一条**必须如实写入 brief**：本轮的开轮理由**不是**「数据变大」，而是**操纵强度修正**（见 ④）。
这同时是 0077 否决 H-C 的同一条几何事实的**另一面**——H-C 的操纵在新实例上变弱，
H-B 的操纵**与网格无关**，故只有 H-B 值得在新制度上重问。

**④ 修法（唯一因子，逐字冻结）：只加一个 `softmax temperature`/缩放，不改任何其它东西。**
现状 `scores = (value @ q)/√dim`。候选臂改为 `scores = (value @ q)·scale/√dim`，`scale` 为**冻结常数**
（不是可学参数），使初始有效打分幅度与同层投影可比。**两臂都带 `scale`**（即 pooled 臂不退化成旧
`pooled`）：这样**唯一因子是 `pooled` vs `spatial` 在同等打分幅度下**，而不是「有没有 `scale`」。
`scale` 的取值由**只读前置**确定：在真实 val 批次上量出 `std(v·q/√dim)` 与同层投影输出量级，
取使两者可比的常数，**在冻结协议里写死并在 brief 预声明**；不做事后调参、不扫 `scale`。
如实声明的代价：**`scale` 是人为放大的**，故本轮测的是「若 query 有足够学习幅度，位置加权是否有效」，
**不是**「优化器自发会学到多大的 query」——后者是另一个问题，本轮不问。

**⑤ 七 gate 逐条。**
- **假设独立**：成立——本轮假设是「在**足够的打分幅度**下，保留 patch 位置能否改变长 lead 读数」；
  旧臂问的是「在**优化器自发生成的**极小幅度下能否改变」。二者操纵不同、结论不可互推。**过**。
- **产物隔离**：全新排他 `outputs/r7_s3_position_scale_65x65_<date>_attempt01/`。**过**。
- **计算资源**：照 R2 实测（每臂训练 11.92 h + 五 lead 评分 0.81 h = 12.73 h；6 臂 ≈ **76.4 GPU-h**），
  双卡共驻；R2 实测每卡峰值 4.9 GiB ≪ 门槛 11.7 GiB，本臂**模型零新增大张量**（+192 参数），
  `estimated_peak` 沿用 R2 实测值。**过**。
- **数据实例**：同一 65×65 多年 store、同一 treatment 清单、同一 val 2022。**过**（与 R2 共享只读实例）。
- **可变状态**：不改 `model/**`（`scale` 由 spec 字段驱动，若需新增字段则属模型改动，见 ⑥ 的代价）。**过**。
- **可独立验证**：`scale` 常数、`|position_query|`、`zero_query_is_pooled` 恒等反证、两臂
  `pathway_init_sha256` 相等，全部可复算。**过**。
- **多重比较**：本轮只比 B→C 一个因子、5 lead、3 seed，与 R2 的读数是**不同轮次不同因子**，
  不与 R2 合并解释；`r`/alpha 按科学合同照常累积。**过**。
⇒ **七 gate 全过**，与 0077（H-C 仅「假设独立」不过）形成对照。

**⑥ 实测的额外前置：typed-evidence 通路在新制度的主线上**不存在**，本轮必须整条重建。**
这是本 ADR 起草后**才**实测到的、会改变成本与设计的事实，必须写在前面：

- 当前主线（R1/R2 的父与两臂）**不启用** typed evidence：R1 `attempt02`、R2 的 `control`/`candidate`/`parent`
  三处 `typed_evidence_mode` **全为 `None`**，其 spec 甚至不带 `typed_evidence` 字段。
- 扫描 `outputs/*/protocol.json`：**只有** H-B 轮（`r7_s3_typed_spatial_20261014_attempt01`）启用了它
  （`pooled`/`typed_routing` 与 `spatial`/`typed_spatial`）。即该通路在 H-B 之后**没有**进入主线。
- 键集实测：当前迁移父 **155** 键、**0** 个 `typed_evidence.*`；H-B 的 spatial checkpoint **164** 键、
  **9** 个 `typed_evidence.*`（`conv.weight/bias`、`norm.weight/bias`、`projections.{0,1,2,3}.weight`、
  `position_query`）；**「只在当前父里」的键为 0**，即当前父是 H-B 键集的**真子集**。

⇒ **本轮不是「在现有父上加一个 `scale`」，而是要**重新启用一条已被主线放弃的通路**，并为其 8 个
（非 query 的）张量提供初始化。**这与 H-B 当年「从已注册父出发」的前提不同**：H-B 的父**带**这 9 个张量
（当年是用 `expand_parent_state` 从带 typed 的注册父扩张的），本轮的主线父**不带**。可行的初始化只有两种：
① 从 H-B 归档的 spatial/pooled checkpoint **迁移**这 9 个张量（`pinned-artifact-replay` 路线，只读、有 SHA 钉）；
② 在 `isolated_stream()` 下**新初始化**，并把「两臂这 9 个张量逐位相同」作为桥的一部分断言。
**本 ADR 不拍板选哪种**——它属执行设计（照 0074 的形式另立 ADR），但**必须在 brief 里如实写明
「本轮同时重新启用了一条非主线通路」这一事实**，否则读者会把本轮读数误读成「在主线上给位置加权」。

**⑦ 必须如实写明的代价与不确定性。**
- **`scale` 引入了一个新的自由常数**：它可能被质疑为「调参直到显著」。防护：常数在**跑前**由只读
  前置量出并写进冻结协议，**不扫、不改、不看读数后调**；brief 预声明该常数与量法。
- **`scale` 几乎肯定要动 `model/**`，实测已确认。** `_build_typed_evidence`（`model/process_forecast_r7.py:152-157`）
  对 `typed_evidence` 的字段集合做**精确相等**断言
  （`expected = {channels, denorm_mean, denorm_std, field_scale, field_mean, field_std, field_active}`，
  `set(fields) != expected` 即 `raise`），故 `scale` **无法**经现有 spec 字段传入——必须新增字段或新增
  `position_scale` 参数，即**改 `model/**`** ⇒ `model_code_sha256` 移动 ⇒ 按 0075 先例重绑父钉。
  **这是本 ADR 的既成代价，不是待确认项**；R2 正在跑的 91 项执行闭包**包含** `model/typed_evidence_r7.py`，
  故该改动**必须等 R2 的 seed/reading 阶段全部结束**才能落地（否则 R2 的 `validate_protocol`
  会以 "execution source changed" 拒绝继续）。
- **正向结果也不能证明「位置保留是长 lead 的瓶颈」**：只证明「在某个被放大到与投影可比的幅度下，
  位置加权改变/不改变读数」。幅度是人为选的，不外推到优化器的自然解。

## Decision

1. **开轮**（顺位到 R4）：单因素两臂在**新制度**上跑 `pooled` vs `spatial`，**两臂共用同一个冻结
   `scale`**，其余逐字沿用注册配方。**唯一因子是聚合方式**（在同等打分幅度下）。
2. **先做只读前置**（零 GPU，且**必须等 R2 的 seed+reading 阶段全部结束**）：① 在真实 val 批次上量
   `std(v·q/√dim)` 与同层投影输出量级，定出冻结 `scale`；② 改 `model/**` 承载该常数
   （字段集是精确断言，见 ⑦，躲不过），按 0075 先例重绑父钉并复算 `model_code_sha256`；
   ③ 立执行设计 ADR（照 0074 的形式）后再开轮。**前置未完成不进 round-guard。**
3. **预声明出口 (a)–(d) + 桥 (e)**（格式照 `docs/goals/s3-year-coverage.md:68-79`）：
   - (a) C 的 72 h t2m `full` skill **三 seed 全部 > 0**；
   - (b) C−B 的 72 h t2m ΔRMSE **三 seed 全部 < 0**；
   - (c) C 的 48 h skill **三 seed 全部 > 0**；
   - (d) C−B 在 6/12/24 h 的 **seed 均值** ΔRMSE **≤ 0**。
   全真 → 只提请独立复核；任一假 → 关闭**「位置保留」这一支**（不扫 `scale`、不加 seed、不换聚合族）。
   - 桥 (e)：`position_query` 清零 ⇒ 权重**逐位均匀** ⇒ C 塌回 B（`zero_query_is_pooled`、
     `zero_query_max_abs == 0`）；两臂 `pathway_init_sha256` 同 seed 相等；`scale` 逐字相同。
     失败只记 `identity/engineering unresolved`，不进 (a)–(d)。
4. **不得使用的动机**：**不得**写「旧臂只跑了 1.12 epoch / 欠训练」。旧臂 1.12 epoch 是实测，
   与本轮的开轮理由无关；本轮理由是 §Context ② 的**弱操纵自证**与 ④ 的**幅度修正**。
5. **不改任何已冻结判据、不改 `docs/plans/0025` 正文**（计划里「弱操纵」那句与 §Context ② 一致，
   无需更正——这与 H-C 那条不同，后者已由 0077 记明「更强操纵下未测」不成立）。
6. **R5（训练信号族）保持未动**；本轮一次只跑一个臂，GPU 由统一父调度按共驻余量串行。

## Consequences

**变容易的：**
- 队列里唯一**原页自己指明了解锁条件**的轴得到正确处理：不是把 null 当结论，也不是换名重开，
  而是修正被自证无效的操纵强度。
- 与 0077 共用同一套几何测量，两条处置**互相校准**：H-C 在新实例上变弱（否决），
  H-B 与网格无关（可开）。这比分别论证更可核查。

**变难 / 代价（如实列出）：**
- **`scale` 是人为常数**：本轮不可能回答「优化器自然会学到多大 query」。**可行区间已实测**
  （`torch.manual_seed(7)`、P=1089、`|q|=0.0125`、LayerNorm 后的单位尺度 token、20 次抽样口径）：
  以归一化熵（1.0 = 均匀）与 `max weight × P`（1.0 = 均匀）为判据，

  | `scale` | 打分 std | `max w × P` | 归一化熵 | 读数含义 |
  | ---: | ---: | ---: | ---: | --- |
  | 1（旧臂量级） | 8.74e-4 | 1.003 | 1.0000 | **弱操纵**：与池化不可区分（旧臂所在处） |
  | 100 | 8.74e-2 | 1.330 | 0.9995 | 仍近均匀 |
  | **1000** | **8.74e-1** | **12.17** | **0.9435** | **可用区**：加权显著但远非 one-hot |
  | 1e4 | 8.74 | 698.0 | 0.1720 | 近 one-hot，已偏离原假设 |
  | 1e5 | 87.4 | 1089（饱和） | — | 退化成「只挑一个位置」 |

  ⇒ brief 须把 `scale` 的**可行区**定在使归一化熵落在约 `[0.90, 0.99]` 的区间（上表对应 ~1e3 量级），
  并在冻结协议里写明「熵 < 0.5 视为退化成 one-hot、该轮读数不得用于判定原假设」这一**跑前**判据。
  数值仍需在**真实 val 批次**上按 §Decision 2 前置复测后定稿——上表是量级依据，不是最终取值。
- **可能触发模型修订移动**：若 `scale` 需要新 spec 字段，`model_code_sha256` 移动 ⇒ 父钉重绑
  （0075 先例第三次/第四次执行），R2 的登记要等到该移动**之后**才不受影响。**这是本 ADR 最大的
  执行风险**，故 §Decision 2 要求前置先做、先定。
- **+192 参数仍旧不是逐位对齐**：与旧臂同样的已声明差异（`+0.13%`）继续存在，不得声称参数量相等。
- **本轮读数与 R2 不合并解释**：两个不同因子、不同时间；`r`/alpha 照常累积，不因两轮同实例就合并。
- **不产生「位置保留是否必要」的一般结论**：只在被选定的 `scale` 下回答。

**备选方案与否决理由：**
- **备选 A：维持 0077 的处置，连 R4 一起否决。** 否决：H-B 的关闭依据是**操纵强度缺陷**且原页
  自证，与 H-C 的「null 已足够强」性质相反；把两者一并否决会把「弱操纵的 null」当成结论。
- **备选 B：把 `scale` 做成可学参数。** 否决：那会同时改「有没有 `scale`」与「聚合方式」两个因子，
  且可学参数会重新落回旧臂的病态（初始化 0 附近学不动）。
- **备选 C：不用 `scale`，改初始化尺度。** 表面等价，但改初始化会同时改两臂的共享随机流
  （`pathway_init_sha256` 可能不再相等），破坏同 seed 逐位一致的桥。**否决**。
- **备选 D：在 129×129 上跑以免动 spec。** 否决：不存在 129×129 的多年源（0056 前提二），
  且计划 0025 §8 禁止新增下载。
