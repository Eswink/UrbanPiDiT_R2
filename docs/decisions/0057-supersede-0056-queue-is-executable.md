# 0057 — 取代 0056：计划 0025 §4.2 的队列**可以**按 §4.4 开轮（0056 把准入判据读窄了）

- **日期**：2026-10-25
- **状态**：accepted
- **取代**：supersedes 0056（`docs/decisions/0056-closed-axis-reevaluation-admission.md`，已标 `superseded by 0057`）
- **范围**：`docs/plans/0025-training-speed-observability-axis-reeval.md` §4 的 W3 队列
- **依据**：计划 0025 §4.2/§4.3/§4.4 原文；0056 记录的实测（保留）；`AGENTS.md` 的「不静默改写历史 / 如实留痕」

## Context

**0056 的实测发现仍然成立，本 ADR 不改它**：六条已关闭臂（气候态锚异常反馈、H-C 全局混合、
空间梯度损失、dense 12 步监督、final-only 草稿监督、显式 tendency 输入）的冻结 `protocol.json`
都是 `input_windows=2360`、`usable_windows=2140`、`updates=2400`、`batch_size=1`
⇒ **每臂 1.12 个 epoch**，且 `region`（129×129、`interior_32`、4,225 格、`mask_sha256 4a2a576b…`）
逐字相同。也就是说，**计划 §4.3 引用「treatment 只看到约三分之一 epoch」时，说的不是这些臂**——
那句话来自 65×65 的 FY 全年覆盖轮，不是 129×129 的架构/训练信号臂。

**但 0056 的结论过强，必须更正。** 它把 §4.3 的使能制度读成了**只有**「匹配算力」这一半：

> §4.3 原文：「使能制度不是『更多数据』，而是『**数据 × 匹配算力**』」

这是一个**合取**。已关闭臂满足的是「匹配算力」那一半（1.12 epoch），**不满足**「更多数据」那一半
（它们跑在 129×129 的 5 年实例上，2,140 个可用窗）。因此新制度相对它们**仍然是新的**，
0056 由此推出的「使能制度无法用来说明不是同一族」是**非推论**。

第二处读窄：§4.4.5 禁止的是「**换名重开**」，即换了名字而**没有**换假设、没有换制度。
本队列的每一轮相对已关闭臂换的是 **store（129×129 5 年 → 65×65 22 年）、网格、监督域
（`interior_32` → `full_grid`）、数据跨度**，这正是「不是同一族」的**实质内容**，不是它的反例。

第三处读窄：§4.3 写的是「案上没有任何文档授权『因数据变大而重开旧轴』⇒ **因此重估的正当性必须由
新 ADR 明确论证**」。这句要求的是**去做论证**，并**不是**「论证一旦不顺就永久不开」。
0056 把「需要论证」读成了「已经论证失败」。

## Decision

1. **取代 0056。** 0056 的事实（旧臂已 1.12 epoch）保留为对计划 §4.3 前提的**更正**；
   0056 的结论（四条都不开轮）**作废**。
2. **队列按 §4.2 顺序可执行**：① 气候态锚异常反馈 → ② 全局混合 H-C → ③ 位置保留 H-B →
   ④ 训练信号族。每条按 §4.4 走完：新 ADR（四段齐全、Consequences 含负面后果）→ 新 brief
   （预声明出口 (a)–(d) + 桥 (e)）→ 七 gate → 冻 `protocol.json` → 跑 → 登记四件套。
3. **每条 ADR 必须显式论证「与已关闭旧臂不是同一族」**，并**如实写明**它的**新制度是什么**：
   本队列的新制度 = 「65×65 多年 store（2000–2021 train / 2022 val，`full_grid` 4,225 格）
   × 每臂 ≥1 epoch」。**不得**再写「因为旧臂欠训练」——实测表明旧臂不欠训练。
4. **必须如实声明的代价**：换网格与监督域之后，本轮读数与已关闭臂**不可直接比较**；
   已关闭臂的结论（例如气候态锚的 F−N 五 lead 全负、72 h −0.321 K）**对本轮没有约束力**，
   反之亦然。这不是缺陷，是本制度的定义；但它必须写在 ADR 的 Consequences 里。
5. **排除项不变**：SAM / zero-base decoder / plain EMA / 长 lead 权重 / rollout 剂量 / depth / width
   仍不开（方向明确的负结果，不是 null）。
6. **命名纪律不变**：`H-D` 一律写全名（`dim` 192→256 的**容量宽度轴** vs **气候态锚异常反馈**）。

## Consequences

**变容易的：**
- 计划 0025 §4 的队列恢复为**可执行**，不再停在「论证不成立」的死结上；四条轴各自有明确的新制度、
  明确的预声明出口与明确的登记路径。
- 0056 的实测把「旧臂欠训练」这个**错误前提**从案上摘掉了：以后写这四条轴的 ADR 时，
  动机必须诚实地写成「在新制度下重问机制」，而不是「让旧臂训练久一点」。

**变难 / 代价（如实列出）：**
- **这是一次纠错，不是一次新发现**：0056 已在分支上、已进索引，本 ADR 追加而非改写它
  （0056 标 `superseded by 0057`，文件与内容原样保留），因此案上会留下「曾判不开轮」的痕迹——
  这是刻意的：读者应当看到判据是怎样被读窄又怎样被更正的。
- **成本真实**：每条轴 3 seed，且「每臂 ≥1 epoch」在 22 年清单上是 **32,142 updates**
  （实测 batch=1 时约 1.86 s/update ⇒ 单臂约 16.6 h）。若 §4.3 的 exposure 落在 22 年清单上，
  单条轴就是 ~100 GPU-h / ~50 h 墙钟量级；batch 由用户按 §5 探针定，batch 2 可把墙钟压到约 0.64×、
  batch 4 约 0.46×。**这一条必须在每条 ADR 的预算里用实测定、不拍脑袋**（照决策 0053/0055 先例）。
- **与已关闭臂不可比较**：同一机制在 129×129 5 年实例上的读数**不能**用来预测本轮结果；
  两条证据线只能并列陈述，不能合并解释。
- **判据仍不放宽**：本 ADR **不**改任何阈值、不重开已冻结的出口、不把「换实例」当作「同一族的续作」。

**备选方案与否决理由：**
- **备选 A：维持 0056（不开轮）。** 否决：它把一个合取读成单边，把「需要论证」读成「论证失败」，
  与 §4.3/§4.4 原文不符；且它实际上替用户改变了研究方向，而方向属用户（决策 0030）。
- **备选 B：只开 ①，其余三条不开。** 否决：§4.2 给了队列顺序，没有给「只做一条」的授权；
  是否缩减队列是用户的判断，执行者不自行缩。
- **备选 C：把队列整体交回用户重批。** 否决：用户已在计划 0025 里逐条授权了队列与程序（§4.4），
  本轮要做的是**执行**它，不是再次请示。
