## Context

毕业论文题目是「基于深度学习的物理信息混合天气预测研究与应用」，因此**物理信息必须有真实贡献**。
这一条不可让渡：无论贡献发生在前向路径还是后处理，都不能只是命名。

到目前为止该题目下的九轮实验全部为负：

| 轮次 | 改了什么 | 结果 | 成本 |
| --- | --- | --- | --- |
| C1 | 无目标物理约束束 | 开轮前否决：分析场被罚 10.2×，8/8 方向反 | 0 GPU-h |
| C2 | 导数域目标匹配 | 15/15 (lead, seed) 全负 | 66.99 GPU-h |
| Stage P | 谱几何前置 | `skip-q`，三方向全不过 | 0 GPU-h |
| Stage R | 后处理振幅校正 | 85/85 全劣化 | 0 GPU-h |
| Stage C | 缺口衰减律 | α=0.05111，减半需 775,102× 训练量 | 0 GPU-h |
| Stage A | β_j AMSE-analogue | 振幅升 +0.114…+0.125，skill 9/9 全降 | 21.83 GPU-h |
| 城市静态 | 三臂输入消融 | (a) 假 ⇒ 按预声明关闭 | 20.46 GPU-h |
| 平衡诊断 | 四物理平衡作评价轴 | (a) 假 ⇒ 记负；(b)(d) 真 | 5.65 GPU-h |

本轮为寻找可行位置又做了七项只读判决性测试（0 GPU-h），**全部为负**：

1. 物理失衡 → 误差大小：逐 lead corr 最大 **0.2676**，lead 12 为 **−0.0164**
2. 物理失衡 → 误差空间图样：中位 Spearman **0.048–0.074**，打不过 `|∇z500|`（0.067 vs 0.131），
   剔除后残差仅 **+0.010**
3. 谱增益校正：`g ≤ −1` 恒等于 box5（残差 **0.000e+00**）
4. 低秩平滑带：随 K 增大退化到平坦带，被块 b=4 支配
5. 平衡子空间带：`R²_bal`=**0.110**，`δz` 仅占误差方差 **6.0%**
6. case 自适应缩放：oracle 的 `P(all)`=0.005，**低于**基线 0.058
7. 地转投影：20/20 RMSE 全升；`ws_ag` 的改善是**构造恒等式**

第 7 项的失败给出了本轮的关键机制证据：`corr(v_a, v_g 误差)` = **−0.79…−0.96**，
即模型的非平衡残差在**补偿**一个错误的 `v_g`；而 `v_g` 偏强（1.12–2.04×）的根源是
**z 的细尺度噪声是真值的 2.56×**（风场 f13 反而**低于**真值 0.44–0.89×）。
⇒ **要修的是 z 的高频误差，且必须在前向修**——事后投影会拆掉模型自己建立的补偿，
这条已由「给真值 z 的完美 `v_g` 在 lead 6 的 250 hPa 仍差 43%」独立佐证。

## Decision

### D1 — 物理信息以**前向输入证据**形式进场，不加任何 loss 项

C1 的散度/质量一致约束与 C2 的导数域匹配都已按预声明关闭，且 C1 的否决理由是
「对分析场的惩罚是模型的 10.2 倍」，即真实大气比模型更不均匀，约束方向本身错了。
因此本轮**不新增任何物理损失项**，物理量只作为**输入证据**进入前向。

这正好落在 `model/typed_evidence_r7.py` 已有的三条路径上：四个局地物理场
（850 hPa 散度、850 hPa 涡度、850 hPa 温度平流、850–500 hPa 静力稳定度）由纯 torch 球面算子
从 `X_t` 与模型自己的初始草稿 `Y_0` 算出，经 patch 编码后加到前四个 anchored 证据槽，
**在第一步递归之前**。递归之后的一切不动。

### D2 — 用 #79 已注册的容量匹配三臂，不发明新架构

`#79`（`docs/R7_S2_79_TYPED_EVIDENCE.md`）已在**参数量 3,097,571、FLOPs 16,776,992,640
逐位相等**的三臂对照下拿到 **6h/12h 双 lead `supported`**（三 seed 同号，t2m −0.0533 K）。
机制核验逐条留痕：off 臂首步状态与旧实现**位级相同（差 0.0）**、扰动任一类型只移动其对应槽位
（4×4 到达矩阵**严格对角**）、毒化未来标签对 forecast 是 no-op。

本轮沿用同一设计的三臂：

| 臂 | `typed_evidence_mode` | 物理场 | 类型路由 |
| --- | --- | --- | --- |
| A incumbent | 未设（生产配置） | 否 | — |
| B generic | `generic_fusion` | 四场融合到一个投影 | 否 |
| C typed | `typed_routing` | 每场独立投影 | 是 |

**主判据是 `C − B`**，因为只有 B 与 C 的参数与算力逐位相等，
所以只有这个差能把增量归因给**物理类型结构**而不混杂容量。
`B − A` 是次要判据，回答「物理证据本身是否有增量」。

### D3 — 预算从 400 updates 提到 32,132（4 epochs），这是本决策的实质

`#79` 只跑了 **400 updates**（`scripts/study_r7_79_typed_evidence.py:41`），
而仓内剂量阶梯证明训练预算在这里是主导变量：

| point | updates | epochs | t2m 6h | 72h | skill@72h |
| --- | ---: | ---: | ---: | ---: | ---: |
| p0025 | 2,008 | 0.25 | 2.2862 | 3.7293 | +0.0981 |
| p1000 | 8,033 | 1.00 | 2.2474 | 3.6006 | +0.1593 |
| p4000 | 32,132 | 4.00 | 2.1109 | 3.4446 | +0.2305 |
| p1600 | 128,528 | 16.00 | **1.8605** | **3.3765** | **+0.2607** |

15/15 格点单调改善，仓自己的饱和判定是 `unsaturated`（Δ=+0.030124 > 0.01）。
**所有已关闭的物理对照臂都跑在 0.075–0.5 epoch**，所以「物理机制无效」这个结论的
适用域只有不到半个 epoch。本轮选 4 epochs，是因为它是仓内**已被证明有实质 skill 的档位**
（p4000 的 72h skill +0.2305），且成本（≈31 GPU-h）在软预算内。

### D4 — 段 B 先用 0 训练成本把「是否需要 16 epoch」变成数据问题

p1600 保留了 **26 个 checkpoint**（每 5,000 步），**只有端点被评过分**。同一轨迹、
同一 seed、同一父、同一 cosine horizon ⇒ 组内剂量曲线，Δ 不带运行间方差，
严格强于四次独立长跑（后者跨了两个 `training_code_sha256`）。
另外 `evaluate_local` 接受裸 `reasoning_steps`（不需要 controller），
所以推理深度 K 也是免费旋钮，且它直接是模型自身递归机制的产物。

段 B 先跑，结果决定段 A 是否需要 16-epoch 档位。**16-epoch 档位本轮不授权。**

### D5 — 判据冻结，且「未测」必须是 `null`

(a) `C − B` 在 ≥2 lead 上同号为负 + 三 seed 一致 + block bootstrap 95% CI 排除零
(b) `B − A` 在 ≥2 lead 上同号为负
(c) 若 (a) 真而 (b) 假，**只能**声称类型结构，不得声称物理增量
(d) 同臂在 4/16 epoch 上增量方向一致
(e) z500@72h 相对 A 臂恶化 ≤ 5%
(f) 预检全真

任一臂缺失时该子句返回 `None`。这是 `da1ed00` 那次「正则把空 body 默认成 false、
卡片与读数相反」的直接修正：**未测 ≠ 假，也 ≠ 真**。

### D6 — 族判别：本决策不是重开任何已关闭的轴

| 已关闭 | 本轮 | 差别 |
| --- | --- | --- |
| 0048 容量轴（dim 192→256、depth 4→8） | **不动结构** | 参数量在 A→B 只增 148,800（+4.5%，是既有通路的固有成本），B 与 C 完全相等。不扫 dim/depth |
| EMA / SWA / 权重平均（永久关闭） | 不做任何权重平均 | —— |
| 长 lead 权重 0.5→1.0（关闭） | 不改 loss 权重 | 物理权重向量逐字沿用 `(1,.5,0,.5,0,0,0,.5,0,0,0,.5)` |
| C1 物理约束损失 / C2 导数匹配 | **不加任何 loss 项** | 物理量是**输入证据**，不是惩罚项。C1 的惩罚对象是「物理量之间的关系」，本轮的输入是物理量本身 |
| Stage R 谱振幅 / 低秩带 / 平衡带 / 地转投影 / case 自适应 | 全部不触碰 | 本轮已逐条实测关闭，且都发生在**事后**；本轮发生在**前向** |
| 城市静态协变量 | 不触碰 | 那是 `S(x,y)`，与动态通道无函数关系；typed evidence 是**同期可导出的派生量** |

**必须承认的相似性**：`record:s3-typed-spatial-result` 关闭的是 `typed_routing → typed_spatial`
的聚合方式，当时的判据是「B→C `|Δrmse| ≤ 3.2e-6 K`」，即在 2,400 updates 下
**类型路由与位置聚合都无增量**。本轮的 `C − B` 复用同一对臂，**但预算从 400/2,400 提到 32,132**。
差别是**剂量**，不是机制。这一点必须在证据页写明：若本轮也为负，则
「typed evidence 在 0.075–4 epoch 全域无效」才成为可引用结论；若为正，
也必须承认它只在 4 epoch 成立、且不能回溯为「之前那轮错了」。

## Consequences

**变难的地方**：

1. **成本从 0 变成约 39 GPU-h**。段 B（8.3）+ 段 A（30.9），全部在软预算 32 GPU-h 内需
   记 overrun。账本 `remaining_gpu_h` 已是 **−599.436628**（cap 20.0 / used 619.436628），
   本轮不改变「无总 GPU-h 上限、账本只记账」的处置，但必须逐行登记。
2. **归因比 #79 更弱，不是更强**。`generic_fusion` 与 `typed_routing` 的差别是
   「融合发生在池化前还是后」，不是「有无物理信息」。所以 (a) 即使为真，
   可写的结论是「物理量必须按其物理类别路由」，**不是**「物理信息有用」。
   后者只能由 (b) 支撑，而 (b) 的对照 A 臂少了 148,800 个参数。**这个容量差无法消除**，
   只能如实申报——它是既有通路的固有成本，不是本轮的设计选择。
3. **z500@72h 护栏 (e) 有真实的失败风险**：p4000→p1600 的 z500@72h 已从 427.35 升到 445.78
   （+4.3%），说明**预算增加本身就在恶化这项指标**。若 (e) 为假，即使 (a)(b) 真，
   结论也必须限定在 t2m，且必须写明动力学指标反向。
4. **4 epoch 可能仍不足**。若 (a)(b) 都假而段 B 显示未饱和，正确动作是开 16-epoch 档位，
   **不是改判据**。这条写进执行源，防止执行者用「剂量不足」为由绕过负结果。
5. **三 seed 是致性证据，不是显著性检验**。block bootstrap 的 CI 是对 case 的，
   不是对 seed 的；三 seed 只用来排除「单次运行偶然」。
6. **GPU 共驻**：延迟与内存观测含邻居负载；每次 spawn 前必须只读核对余量，
   **禁止**对非本实验进程发送任何信号。

**代价**：本轮若全负，物理信息线在「前向输入」「损失侧」「后处理」三个位置全部测过，
题目里的「物理信息」将只能依赖**机制性发现**（`corr(v_a, v_g 误差)`=−0.79…−0.96、
z 的 f13 噪声 2.56× 经梯度放大成地转失衡）而非 skill 增量。这一点在动手前就承认。

**Trade-off**：选 4 epoch 而不是 16 epoch，是用「可能因剂量不足而假阴」换「成本可控且能先用
段 B 判断是否需要更多」。这个交换是显式的：段 B 若显示未饱和，则 4-epoch 的负结果
必须标注为「在未饱和预算下」，不得外推为「物理证据无效」。

## 已否决的替代方案

| 方案 | 否决理由 |
| --- | --- |
| 直接跑 16 epoch（123 GPU-h） | 段 B 未跑前无法论证这个预算必要；且 0048 的教训是「用算力辩解」被明确禁止 |
| 只在 2,400 updates 重跑三臂 | 那正是 `s3-typed-spatial-result` 已关闭的剂量，重跑无新信息 |
| 加物理 loss 项 | C1 的分析场惩罚是模型的 10.2 倍，方向本身错了（决策 0094） |
| 做事后物理投影 | 本轮实测 20/20 全升，且 `ws_ag` 改善是构造恒等式 |
| 用 conformal 包装成「物理贡献」 | 场级覆盖崩塌是真的，但它与物理无关；塞进物理叙事就是换名 |
