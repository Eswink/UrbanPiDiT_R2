## Context

**① C1 已被前置否决，C2 是 Stage C 剩下的那一半，且它与 C1 不是同一件事。**
0094 实测：C1 的散度项对**分析场**的惩罚是模型的 10.2 倍（8/8 例），因为真实大气的逐层散度
**不是**近零的（`mean |∇·(u,v)| = 2.51e-05 s^-1`），而模型场比真实更平滑。
C2 不惩罚「散度的大小」，而惩罚**预测的散度与目标的散度之差**：

```
L_c2 = w_div * mean( ((∇·pred − ∇·target)/s_div)² ) + w_vort * mean( ((∇×pred − ∇×target)/s_vort)² )
```

`pred = target` 时**逐项精确为零**，最优解**就是**真值。因此 0094 那条「真值被罚更多」的
不等式在 C2 上**不存在**——它不是被绕开了，而是根本不适用：C2 是**有目标**的匹配，不是
无目标的约束。

**② 族判别（决策 0084 §6 的前置）。** 与已关闭的空间梯度损失逐条对比：

| | 已关闭的空间梯度损失 | **C2 导数域目标匹配** |
| --- | --- | --- |
| 惩罚对象 | 预测**自身**的空间梯度 `‖∇pred‖²` | 预测与目标**导数场之差** |
| 是否读 target | **不读** | **读**（逐点、逐 lead） |
| 最优点 | 常数场（退化） | **真值本身** |
| 真值处的值 | **不为零**（真值有梯度） | **精确 0.0**（实测，见 Context ③） |
| 梯度方向 | 把场推向更平滑，与真值冲突 | 把预测的**旋度/散度结构**推向目标 |
| 与 skill 的关系 | 实测三 seed 全负 | **未测**；但最优点含真值，故不必然牺牲 |

**决定性区别**：空间梯度损失在**真值处不为零**（真实场有梯度，惩罚会试图抹掉它），
C2 在**真值处精确为零**。这是可检验的差别，不是措辞。

**③ 前置检验已按 0094 的方法做完，两项都通过（本 ADR 的依据，实测）。**

口径：65×65 多年实例、**train manifest**（不读 val、不读 test）、4 个 case
（1000/9000/17000/25000）、p1600 端点（`update_0128528.pt`）、CPU 前向。

尺度常数由**分析场自身分布**导出（不是拟合读数）：`s_div = 2.5665e-05 s^-1`、
`s_vort = 3.5089e-05 s^-1`（4 个 case 的分析场 `mean |div|`、`mean |vort|` 的均值）。

| 检查 | 结果 |
| --- | --- |
| **(1) 真值处为零** | `pred = target` 时 `div 0.000e+00`、`vort 0.000e+00` —— **精确零** |
| **(2) 模型处为正** | 4 个 case 的合计 `4.2724 / 3.5744 / 3.5987 / 3.5220`，全部 ≫ 0 |
| **(3) 剂量** | `L_c2 / L_mse` = **1.287 / 0.805 / 0.707 / 0.823** —— 与 MSE **同量级** |

第 (3) 条正是 C1 栽的地方：C1 原始实现是 `1e-11–2e-6` 对 `L_mse ~ 1`（梯度比低至 2.7e-10），
**完全不能作用**；C2 无量纲化后是 MSE 的 **0.71–1.29 倍**。两者相差约 5 个数量级
（C2 的束值 3.5e-01–4.3e-01 对 C1 的 1e-11–2e-6），不是程度差别而是「能不能作用」的差别。
**这也是 C1 的教训被实际用上的地方**：若不做无量纲化，C2 会重演同一个剂量陷阱。

**一处已更正的数字**：初次探针报的是**未加权**的 `div + vort` 之和除以 `L_mse`
（12.87 / 8.045 / 7.071 / 8.234）。而模块对每项各乘 `w = 0.1`，所以**真正进入目标函数**的
剂量是上表的 **1.287 / 0.805 / 0.707 / 0.823**。两个数都如实登记：前者是「两项之和」，
后者是「加了权重之后」；本 ADR 的判据用后者。这次更正由「用模块本身重算」发现，
不是靠再读一遍脚本——**探针与模块必须走同一条代码路径**，这一条已写进 §Decision 9。

## Decision

**1. 新建 `training/r7_derivative_matching.py`，两项导数域匹配，读 target。**
`divergence_matching(pred, target, lat, lon, scale, weight)` 与
`vorticity_matching(...)`，复用 `model/r7_process_tensor_diagnostics.py:133,139` 的
`spherical_divergence` / `spherical_vorticity`（**复用算子，不复用 legacy 损失**）。
两项先除以声明的尺度再平方，与 0094 的修正同构。

**2. 单因子开关 `derivative_matching`，默认 off，off 路径不构造任何张量。**
与 C1 同构（`constraint_term` 的早期 `None` 返回模式）；on 时只加两项，**不改模型结构、
不加参数**（`parameter_delta = 0`），故 on/off 差异不能归因于容量。

**3. 权重是**本轮选择**并显式申报。** legacy 没有导数域**目标匹配**项（它的 `w_wind_div` 是
无目标的散度大小惩罚，已被 0094 否证），因此这里没有「沿用原值」可引用。
取 `w_div = w_vort = 0.1`：两项等权（无先验理由偏向其一），且 0.1 使合计剂量落在
`L_mse` 的 0.7–1.3 倍（由 Context ③ 的实测反推），不淹没 MSE 也不被 MSE 淹没。
**这是论证加一次实测的量级选择，不是扫参结果**；不扫 λ。

**4. 预声明出口 (a)–(d)，任一假即永久关闭该支。**
- **(a)** 72 h t2m skill 相对**同代码身份**的 off 臂**不退化**（配对、三 seed 均值 ≥ 0）；
- **(b)** 两项导数匹配在 on 臂的**实测值**相对 off 臂下降（否则「匹配没生效」）；
- **(c)** off 路径**逐位**等于当前实现（无副作用）；
- **(d)** 无判据被改动、`test_read is False`、`scientific_claim: False`。

**任一假 ⇒ 永久关闭「导数域目标匹配」这一支**，不调权重、不换项、不加 seed。

**5. 桥 (e)：与 off 臂的父身份逐 seed 断言**（`model_code_sha256` + 155 张量 `state_digest`），
与 Stage B 同构。本轮无零 query 聚合那类逐位判据，不涉及决策 0082 的 float32 界问题。

**6. 三 seed（41/42/43），配对比较。** 与 C1 设计同口径：配对差需要 seed 来估计方差。

**7. 不改 `model_code_sha256`**（不加参数、不改结构），父可继续使用；
`training_code_sha256` 会变（新损失进训练闭包），故**不能**与 Stage B 的臂作代码身份对照。

**8. 预算按第四点实测重算。** 第四点实测 **1.1096 s/update**（128,528 updates / 142,610.4 s）
是四点里最接近本轮规模的速率；本轮 updates 取 **45,575**（计划 0028 的 5 年清单 × 25 epoch 口径）
会与 65×65 实例不匹配，故**改为在本实例上按 4 epoch 口径 = 32,132 updates**，
与 Stage B 第三点同算力，使「加了 C2」与「只加训练量」可比。
训练 `32,132 × 1.1096 = 35,654 s`；评分按第三点实测 `2,667.1 s`；合计 `38,321 s ≈ 10.65 GPU-h`/arm。
两臂 × 三 seed = 6 次训练 ⇒ **约 63.9 GPU-h**，与计划 0028 的「约 64 GPU-h/轮」相符。
包络 `per_seed = ceil(3 × 38,321 / 3600) × 3600 = 115,200 s`、`hard = 230,400 s`。

**9. 前置检验必须走模块本身，且已完成。** Context ③ 的第一次测量是临时脚本，
报的是未加权和；改为**调用 `training/r7_derivative_matching.py` 本身**重算后，得到加了权重的
剂量 1.287/0.805/0.707/0.823，`pred = target` 仍为**精确 0.0**。本 ADR 的数字以后者为准。
**探针与模块走同一条代码路径**是这里的方法要求：一个绕过模块的探针可以给出与训练时不同的数，
而那种差不会被任何测试发现。冻结前仍须把这次测量以可复算形式写进驱动并记入 protocol。

## Consequences

**负面后果（代价，必须如实列出）**

1. **`w_div = w_vort = 0.1` 是本轮的选择，legacy 无对应原值可引用。**
   依据是等权 + 一次剂量实测，**不是**扫参最优。若结论对权重敏感，本轮无法分辨。
2. **两项混在一起。** 即使 (a)–(d) 全真，也只能说「这个组合没有退化 72 h」，
   不能归因到散度还是涡度。分离实验不在本轮。
3. **三 seed × 两臂 = 六次训练，约 64 GPU-h。** 这是**估计**（按第四点 1.1096 s/update 推），
   不是实测；四点 s/update 极差约 5.7%，故实际可能落在 60–68 GPU-h。
4. **尺度常数由 4 个 train case 的分析场均值导出，样本很小。**
   换 season/region 会变；它们只影响两项的**大小**，不影响 Context ③ 的 (1)(2) 两条，
   但**影响 (a) 判据的灵敏度**。
5. **C2 读 target，因此它不再是「无目标」的物理信息。** 这与主目标里「物理信息」的
   原始意图有偏差：C2 学到的是「像目标的导数场」，不是「满足物理定律」。
   这一条必须写进证据页，不能因为 (a)–(d) 全真就宣称「模型学会了物理」。
6. **`training_code_sha256` 会变**，故与 Stage B、与 C1（若未来重开）都不可作代码身份对照。
7. **单实例、单分辨率。** 65×65 多年实例；129×129 wide 实例未测，散度/涡度是尺度相关量。

**正面后果**：Stage C 剩下的那一半有了可证伪的实验，且它的前置检验**已经通过**
（真值处精确为零、剂量与 MSE 同量级）——与 C1 的前置检验失败形成对照，
说明 0084 §6 的前置是真闸门而不是形式。
0094 发现的两个缺陷（按名取通道、量纲）在 C2 里从第一天就按正确形态实现。

**否决**：
- 沿用 C1 的模块加一个 target 参数（C1 的语义是无目标，混进 target 会让两条支的边界模糊）；
- 把 C2 也做成无目标（那就退回 C1，已被 0094 否证）；
- 扫 λ（0084 §6 的预声明出口要求单因子，扫参会把结论偷换成「某个 λ 下有效」）；
- 在 ADR 复核前冻结协议（Context ③ 的探针须先变成可复算形式）。
