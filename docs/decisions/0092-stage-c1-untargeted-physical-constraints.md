# 0092 — Stage C1：无目标物理**约束**束（散度/质量一致、比湿非负、露点 ≤ T）

- **日期**：2026-11-05
- **状态**：proposed
- **执行前置**：待第三点 attempt02 跑完、按其实测 s/update 重算预算后再执行（见 §Decision 7）
- **范围**：新建 `training/r7_physical_constraints.py`（**不 import** `legacy_v531_full/`）、
  驱动 `scripts/study_r7_s3_physical_constraints_c1.py`、测试
  `tests/test_r7_s3_physical_constraints_c1.py`
- **依据**：决策 0084 §6（Stage C 两轮的开轮前置）、`docs/goals/s3-throughput-and-physics-campaign.md`
  Stage C1、`docs/R7_S3_SPATIAL_GRADIENT_LOSS_RESULT.md`（已关闭的对照）、

  `w_dew_leq_t=0.5` 出自此处）

## Context

**① 这一轮存在的理由：主目标的「物理信息」这一半从未被实验过。**
全仓唯一的物理正则化是空间一阶差分惩罚，且 `gradient_lambda` 默认 `0.0`
（`training/r7_recursive_losses.py`）。守恒、平衡、连续方程、谱损失、CRPS 全部零命中。
legacy 有一份完整的 `physical_consistency.py`，但当前代码**不 import** 它。
C1 是这个空白上的第一次实验。

**② 必须先论证「与已关闭的空间梯度损失不是同一族」，否则不得开轮（决策 0084 §6）。**
这是本轮**最重要的一段**，因为论证不成立就没有开轮资格。

| | 已关闭的空间梯度损失 | **C1 约束束** |
| --- | --- | --- |
| 惩罚对象 | 预测**自身**的空间梯度 `‖∇pred‖²` | **物理量之间的关系**：散度、比湿符号、露点与 T 的序 |
| 是否有目标 | **无** | **无**（三项都不读 target） |
| 最优点是什么 | 常数场（梯度为零最小化该项） | 无散度流场、非负水汽、`Td ≤ T`——**都不是常数场** |
| 梯度方向 | 把场推向更平滑 | 把场推向**满足约束的流形**；对已满足约束的场**梯度为零** |
| 与 skill 的关系 | 已知会牺牲 72 h（实测三 seed 全负） | **未测**；约束在物理上可满足，故不必然牺牲 |

**决定性区别在最后两行**：空间梯度惩罚的全局最优是一个**退化**解（常数场），所以它必然与
「预测真实天气」冲突；C1 的三项在真实大气里**本来就是满足的**，它们的最优解包含真实场，
因此不构成同一种「用平滑换技巧」的交易。**这就是它不是同一族的理由**，而不是「名字不同」。

**③ 三项约束各自的形态（全部无目标、全部对已满足的场返回零）。**

1. **散度/质量一致**：`relu(|∇·(u,v)| − ε)²` 的均值，ε 是数值容差而非可调旋钮；
   真实大气的柱积分散度近零，逐层散度不严格为零，因此这一项**只惩罚超出容差的部分**。
2. **比湿非负**：`relu(−q)²`。物理上 q ≥ 0 是硬约束，违反即非物理。
3. **露点不高于 T**：`relu(Td − T)²`。legacy 用 `w_dew_leq_t=0.5`，本 ADR 沿用该权重
   与 `w_wind_div=0.1`，**但代码在新模块重写**，不 import legacy。

**④ 权重来自 legacy，不是本轮自创。** `w_wind_div = 0.1`、`w_dew_leq_t = 0.5`
（`legacy_v531_full/losses/physical_consistency.py:68-70`）。比湿非负在 legacy 里没有独立权重
（它把 `tp_nonneg`/`tcc_01` 一类可行性项合在一起），因此**本 ADR 必须显式申报**：
q 非负的权重取与露点项相同的 0.5，理由是二者都是「硬物理边界」类的可行性约束；
这是**本轮的选择**，不是 legacy 的数值，必须写进 limitations。

**⑤ 若 C1 赢，不得把束当结论（决策 0084 §6 原文）。** 束内三项混在一起，赢了也只说明
「这个组合有用」，不说明哪一项有用。因此 brief 必须**预注册**后续分离实验的形态，
本轮不做。

## Decision

**1. 新建 `training/r7_physical_constraints.py`，三项约束，无目标，不 import legacy。**
模块提供 `divergence_penalty`、`specific_humidity_nonneg`、`dew_point_le_temperature`
与一个 `physical_constraint_terms(...)` 汇总入口；每项对已满足约束的输入返回**精确 0.0**
（用 `relu` 而非 `softplus`，避免"满足也给一点惩罚"的软化）。

**2. 单因子：`physical_constraints` 开关，默认 off。**
off 路径**不构造任何张量、不做任何计算**，前向与当前实现逐位相同（由源码级断言 +
Stage A 式逐位对照保证）。on 路径只在损失里加三项，**不改模型结构、不加参数**
（`parameter_delta = 0`），因此 on/off 差异不能归因于容量。

**3. 权重沿用 legacy 并显式申报 q 项的选择。**
`w_div = 0.1`、`w_dew = 0.5`（legacy 原值）、`w_q = 0.5`（**本轮选择**，见 Context ④）。

**4. 预声明出口 (a)–(d)，任一假即永久关闭该支。**
- **(a)** 72 h t2m skill 相对**同代码身份**的 off 臂**不退化**（配对比较，三 seed 均值 ≥ 0）；
- **(b)** 三项约束在 on 臂的**实测违反量**相对 off 臂下降（否则"约束没生效"）；
- **(c)** off 路径**逐位**等于当前实现（无副作用）；
- **(d)** 无判据被改动，`test_read is False`，`scientific_claim: False`。

**任一假 ⇒ 永久关闭「无目标物理约束」这一支**，不调权重、不换项、不加 seed。

**5. 桥 (e)：与 off 臂的父身份逐 seed 断言。** 与 Stage B 同构；**不涉及**决策 0082 的
float32 界问题（本轮没有零 query 聚合那类逐位判据）。

**6. 三 seed。** 这是**配对比较**（on vs off 同算力、同父、同 seed），与 Stage B 的
n=1 定标曲线不同：配对差需要 seed 来估计方差。三 seed 是决策 0084 对配对臂的既有口径。

**7. 本轮**不**在第三点跑完前冻结。**
预算必须按第三点 attempt02 的**实测** s/update 重算，不能沿用第二点的 1.1505。
本 ADR 因此是 `proposed`：设计已定、判据已定，**但协议不冻、不跑**，
直到第三点读数落地。这是「估计值不得写成实测值」的直接应用。

## Consequences

**负面后果（代价，必须如实列出）**

1. **q 非负的权重 0.5 是本轮的选择，不是 legacy 的数值。** legacy 没有独立项；
   选 0.5 的依据是"与露点项同类"，但这是**论证而非测量**。若 C1 的结论对权重敏感，
   本轮无法分辨。
2. **束内三项混在一起。** 即使 (a)–(d) 全真，也只能说「这个组合没有退化 72 h」，
   **不能**说哪一项起了作用。分离实验是预注册的后续工作，不在本轮。
3. **散度项的 ε 容差是一个自由度。** 取太紧会把真实大气的非零散度当违反（等于惩罚真实场），
   取太松则该项形同虚设。本轮必须**先冻结 ε 并记录其依据**，不得看了读数再调。
4. **三 seed × 两个臂 = 六个训练，成本约 2× 单臂。** 按第三点实测速率重算前，
   这是**估计**不是实测。
5. **本轮不改 `model_code_sha256`**（不加参数、不改结构），因此父可继续使用；
   但 `training_code_sha256` 会变（新损失进入训练闭包），故**不能**与 Stage B 的臂
   作代码身份对照。
6. **legacy 只读。** 不 import、不复制其类；权重数值是**引用的常数**，
   实现是新的。若未来发现新实现与 legacy 语义不同，那是新实现的问题，不是 legacy 的问题。

**正面后果**：主目标里从未被实验的那一半第一次有了可证伪的实验；「不是同一族」的论证
落在**最优点是否退化**这个可检验的性质上，而不是措辞上；off 路径的逐位等价使 on/off
差异只能来自约束本身。

**否决**：import legacy 的 `PhysicalConsistencyLoss`（它捆了 FFT、梯度、日周期等**已关闭
或未授权**的项，且会引入旧日志键契约）；把三项拆成三个独立轮（成本三倍，且本轮先问
「束有没有用」）；给 q 项编一个"legacy 原值"（legacy 没有这个数，编造就是伪造出处）；
在第三点跑完前冻结协议（预算会是估计值）。
