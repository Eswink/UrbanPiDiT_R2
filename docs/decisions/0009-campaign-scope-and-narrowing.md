## Context（背景）

用户授予了本战役范围内的全部决策权（预算、数据范围、消融设计、是否启动 #66、
#67 协议与封存时机、是否 ff 更新 main、是否关闭 issue），并要求自行拍板并记录理由。
战役在 S3（#65 预诊断 → 归因 → C1/C2/C3 消融）、S4（#66 门槛）、S5（#67 协议与封存）
与并行轨（#68 传输层）上产生了若干**跨任务**的范围与契约决策。

本记录只记录这些**跨任务**决策，不重复各 issue 的结果细节（那些在各自的 `docs/R7_*.md`）。

预诊断给出的关键事实（决定了后面几条决策）：`eps=1e-6` floor 只影响 2/8 个 proxy，
且只削弱**辅助损失**、不污染前向状态；B2/B3 的 `process` 臂在 `process_weight=0`
下功能上等同 `generic`（对齐一个投影即逐位相同）。

## Decision（决定）

六条决策，逐条给出理由。

### D-1 不修 `eps=1e-6` 归一化 floor，先测量其实际影响

在 S3 预诊断阶段**不**改建 store 的归一化，而是先量化 floor 对两个水汽 proxy 的影响，
并查明它能影响哪条路径。理由：修归一化意味着**新 store、新 `data_identity`**，
会让 B2/B3/C1/C2/C3 的全部 checkpoint 被身份检查拒绝（即全部作废）；而预诊断证明该缺陷
**只能削弱辅助损失**、**不能**污染前向状态，所以在打开辅助权重之前它不是阻断项。

### D-2 产物上限越界 → 用「证据保全式剪枝」收窄，不删证据

C1+C2+C3 未剪枝共写 5.758 GiB，使累计达到 **16.03 / 16 GiB**（越界）。按授权
「缩范围解决」，执行 `tools/prune_r7_run_checkpoints.py`：只删除每臂
`training_report.json` 记录的 `selected_checkpoint` **之外**的中间 checkpoint。
理由：剪枝保留全部评估目录、`rmse.csv`、报告、协议与结果 JSON，且**保留**每个
已发布数字所依赖的 selected endpoint（其 SHA256 已在结果文件里）。

### D-3 #66 标 BLOCKED 而不训练停止器

不启动自适应推理、不训练新控制器、不改 `model/r7_halting.py`。理由：#66 的门槛是
「固定深度模型已形成**有用的**精度—成本取舍」，而实测最优 K 的排序只在 6h 跨 seed 一致，
且 6h 的最优 K **就是最贵的 K=4**（收益 0.00%）；同时**固定训练的 K=1 已经便宜 27.9%**，
所以任何自适应策略的上界是「匹配固定 K=1 再减控制器开销」。

### D-4 #67 封存 test：先把范围缩到 1 月重切，再一次性读 test

原先冻结的 B2 段把 test 全切在 **2 月**，而 train-only 气候态桶只有 **1 月**，
`evaluate_local` 因 D-3 设计（skill 必须与预测同 case）**无条件**计算气候态，
于是**任何臂**都无法在该段 test 上评估。授权的越界解法是**缩范围**，故：

1. **重切 held-out 到 1 月内**（`configs/r7_era5_b2_recut_test_january.yaml`）：
   train `[01-01,01-25)` **逐字节不变**（已断言 train 清单字节相等，94 窗口不变），
   val `[01-25,01-27)`、test `[01-27,02-01)`，两者都只需要气候态**实际拥有**的
   `(1,00/06/12/18)` 四个桶。数据源是**已冻结的 `source.nc`**（sha256 记录），
   **无新下载**，store 0.030 GiB。
2. **全臂重训**：`data_identity` 覆盖 `split_time_ranges`，所以旧 checkpoint 被
   正确拒绝，15 个 arm-seed 单元全部重训（≈1.35 GPU-h）。
3. **一次性读 test**：`read_count: 1`，报告 `docs/R7_67_SEALED_TEST_REPORT.md`。

**如实声明**：因为第 2 步，这是**新实验**，本报告**不**声称它确认了此前冻结的
B1/B2/B3/C1/C2/C3 链。test 结果本身是时效依赖的（物理单位下 1275 单元
better 646 / worse 629：6h 245/10、12h 239/16 明显占优，24h 约打平，48/72h 明显更差），
与既有方向一致，构成负结果论文包。

> **2026-09-27 更正**：本条原写作「全部 85 个单元输给零参数气候态」。
> 该计数来自跨单位比较（`rmse.csv` 物理 vs `climatology_skill.csv` 归一化），
> 已确认不成立，详见决策 0010。方向性结论（长时效上 climatology 占优）**仍然成立**，
> 但「全负 85 单元」与「9.09 倍」两条表述不得再引用。

**放弃的选项与代价**：
- 放宽读者的缺桶拒绝：**禁止**（会把 held-out 数据泄漏进基线）。
- 不做重切而把 #67 永远留在 BLOCKED：会缺掉 objective 明确要求的「只读 test 报告」。
- **代价（新增局限）**：重切后的 test 更小——72h 只有 **7** 个 case、48h 只有 11 个；
  val 只有 8 时次（48/72h 窗口为 0），所以**模型选择仍只能用 6h 验证**。
  这些局限已写进报告的 §7。

### D-5 #68 保持「地址约束」边界，不宣称更强的防护

`http_pinned.py` 提供**连接地址约束**（非公网地址永不被拨号），文档明确它**不**提供
allowlist、不检查响应内容、也不保证公网 origin 的性质。理由：可离线证明的是
「被校验的地址就是被连接的地址」与「非公网地址被拒」；无法证明的是「公网 origin 本身可信」。

### D-6 默认策略不改（C2 的 mixed 结果不作为改默认真依据）

`use_forecast_feedback=True`、`spatial_solver_feedback=False` **保持不变**。理由：
`solver_on` 一致变差（85 格里 28 worsened），但 `fb_off`（唯一略正面的改动）同时
**省 10.7% FLOPs**，更像效率观察而非结构结论；#65 C2 明文要求「保留当前默认直到通过
新协议」，而本轮**没有**为改默认真建立新协议。

## Consequences（后果）

**已产生的后果**：

- **已发布数值仍可复现**（D-2）：每次运行的 selected endpoint 保留，其 SHA256 记录在
  `ablation_result.json` / `curriculum_result.json` 中；中间 checkpoint 的删除留有
  `checkpoint_prune_receipt.json`。**代价**：C1–C3 上无法从中间点重启训练。
- **#66 与 #67(b) 以 BLOCKED 收口**，而不是以「未完成」或「假装通过」收口。
  两者都写出了**真实依赖**：#66 缺 M1–M4（见 `R7_66_GATE_AUDIT.md` §4），
  #67(b) 缺一个与 train-only 气候态桶相交的 test 划分。
- **test 仍是未读状态**（D-4）：执行在写出任何 `rmse.csv` 之前失败，0 个指标文件，
  所以将来补做仍是「首次看测试」，不构成多次看测试。
- **安全声明保持可辩护**（D-5）：文档把「地址约束」与「完整 SSRF/DNS-rebinding 免疫」
  分开陈述，避免把可证明的与不可证明的混为一谈。
- **默认配置与 B2/B3/C1 保持一致**（D-6），代价是保留了一个可能更贵的默认，
  直到有新协议。

**未采纳选项的代价（如实记录）**：

- D-1 立即修归一化并重训一切：作废 5 条已冻结实验链（≈2.3 GPU-h 训练 + 全部评估），
  而收益在本轮无法验证。**保留的局限**：C1 的 `aux>0` 臂在一个 2/8 通道近乎常量的
  目标上训练，已在 `R7_65_C1_PROCESS_SUPERVISION.md` §5 写明。
- D-2 停止 C2/C3：会让 #65 的三条消融轴只完成一条，直接损害判据完整性。
  D-2 删除整个无效 C3 运行：会销毁那次 harness 缺陷的实物证据，故特意保留
  （0.945 GiB，pruner 的 fail-closed 检查也拒绝剪它）。
- D-3 训练 gain controller 并调阈值：会产出数字，但门槛不成立时那些数字只能证明
  「控制器能学会复现固定深度」。**代价**：oracle 显示逐样本最优 K 确有变化
  （+6.9~+13.0%），这个头寸未被利用，已如实记为**不可部署**的上界。
- D-4 **已执行**：重切 + 全臂重训（15 个 arm-seed，≈1.35 GPU-h）并一次性读 test。
  它作为**新实验**报告（新 `data_identity`），不声称确认旧链。放宽读者的缺桶拒绝：
  **禁止**（会把 held-out 数据泄漏进基线），未做。
- D-5 加 allowlist：会把「固定官方来源已经足够」变成对任意 URL 的通用代理实现，
  与 #68 计划第 1 条「不必要地实现通用代理」相抵触；未做。**代价**：一个解析到公网
  地址的恶意 origin 仍会被正常连接，这是已声明的边界。
- D-6 把 `use_forecast_feedback` 改为 False（省 10.7% 计算）：当前数据不足支撑改默认，
  且会与 B2/B3/C1 的既有配置产生不一致；未做。
