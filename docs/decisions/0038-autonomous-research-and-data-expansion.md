# 0038 主模型超气候态研究的自主执行与真实数据扩围授权

- **日期**：2026-10-04
- **状态**：accepted

## Context

用户确认此前工作完成，选择下一总体方向：沿 UrbanPiDiT 可思考/递归主模型持续迭代，直到公平超过
当前 train-only climatology，并明确允许获取更多真实数据、下放实验与时长决策权。随后批准计划
`docs/plans/0016-main-model-climatology-campaign.md` 的交付范围及以下具名派生发布授权。
本轮仅落实文档与校检支持，不执行下载、发布、训练、评估或 git 提交/推送。

旧 #70–#75 已按决策 0037 收尾；actual C 的 package 改善不等于超过 climatology，也不能归因
过程语义。新 #76–#79 是待检验的研究建议，不是新科学通过证据。0030 的方向内自主执行仍适用，
但原来的新数据/发布保留边界需要本次前瞻扩围，不能靠“全权”两个字绕过 preflight。

## Decision

1. **新总体方向与唯一主计划。** 后续以 `docs/goals/main-model-climatology-campaign.md` 为新研究
   主计划，以 `docs/R7_MAIN_MODEL_CLIMATOLOGY_PROTOCOL.md` 为新科学合同。旧 V2 收尾不重做，
   不回改其协议、失败、暂停、归档、test 曝光事实或最终判定。性能、机制归因、工程与 goal 状态分别写。
2. **方向内自主决策。** 继承 0030：方法/架构、假设取舍、训练策略、种子/更新数、实验编排、故障
   排查、下一实验、节点推进与每次时长由执行者自行决定，不逐次询问、不逐轮等用户触发。
   无总 GPU-h 上限。每次冻结整轮 `planned_seconds`/`hard_cap_seconds`，软超继续记 overrun，
   硬截止停止该 attempt；不能运行中改已冻结硬截止，增加时长用于下一独立协议。实际成本全额记账，
   简要通知不是请求批准。普通失败先修复，负面终结相关假设，不冻结全部独立主线或无限重复至赢。
3. **免费真实数据下载。** 明确允许为本天气任务分批获取合法公开、免费的区域真实天气数据，包含
   多季节、多年度及独立确认年份。执行者自主选择来源、区域、年份、变量、分辨率和每批数字预算，
   先小 pilot 核 schema/单位、实际速率、解码量、网络量和磁盘峰值后再扩。每批先冻结源/快照/许可、
   split、输出、字节预算、软硬时长、余量门及恢复策略，不默认获取全球全集，不占满共享磁盘。
4. **具名新路径派生发布。** 在第 3 项范围内，执行者可自行审阅并留存
   `prepare_r7_local.py` 的只读 preflight；通过单位/坐标/schema/有限性/完整 source SHA256 核对后，
   本决策即为向**全新、非嵌套、排他 `outputs/` 路径**执行 `--write` 的显式授权，无需逐批人审。
   `--max-raw-gib` 等实际预算仍须传入；`fresh_outputs`、`BUILD_COMPLETE` 和读取身份校验不可省。
   输入文件不修改；不写入、移动或删除 `data/raw|interim|processed`、旧 store、legacy 或已存在产物。
   preflight 通过只是工程资格，不证明科学适用性。失败留 `failed-no-fallback`，不合成替代；新修复
   用新协议/新路径，不通过删除旧部分输出让重试成功。
5. **参考源码与调度。** 联网准备期允许检索一手文献和 clone 所需公开官方源码至
   `outputs/reference_sources/<project>/<commit>/`，固定 URL/访问日/commit/license/hash，提交引用台账。
   镜像隔离只读，不直接 import 或运行上游安装/训练；合法少量移植须保留许可、测试和身份。
   子代理/技能按新主计划触发，planner 不定科学阈值；资料/CPU 可并行，GPU 由统一父调度核共驻余量。
6. **保留边界与外向操作。** 付费数据/资源、GPU 租赁或独占、总体方向改变、main 合并、发版、
   破坏性操作仍需具名许可；force/mirror/删除默认分支、信号邻居、绕 hook、降低安全门禁止。
   新研究 goal 内的工作分支实现/证据提交与推送可按既有 git/SSH 通道自主执行并核精确 CI，
   但本次文档交付不提交推送；不扩展 0037 的 main 写入或 #70–#75 关闭许可到 #76–#79。
   issue 结题不是本科学目标的完成条件。R-006/R-028/R-054/R-009、身份强核、非科学标志与 limitations
   保留；无 cron/常驻守护或会话结束后自建续跑。最终 complete 仍由用户或运行时独立校验裁定。

## Consequences

**变容易的：** 数据量不足、网络慢、逐轮时长或方法选择不再恢复成用户微观调度；可以在准备期并行
资料和 CPU 工作，分批扩到四季/独立年份，按新科学合同持续自主探索并保留失败。

**变难 / 代价（如实列出）：** GPU-h、网络、磁盘、时间与多重探索成本可能持续累积；执行者承担
数据许可、preflight 审阅、split/test 泄漏防护与公平重建基线的责任。新增授权不保证一定超过气候态；
重复确认容易产生选择偏差，须冻结时间块统计、确认序号及 alpha 预算并保留所有失败。新旧 campaign
分别检查和交接，治理文档尚未提交时干净克隆仍无法使用它，不能把本轮本地验证冒称远端 CI。

**备选方案与否决理由：** 每批下载、每次实验和每节点再询问用户不采用，与明确下放相冲突；把授权
解释成付费、全球全集、原地改数据或跳 preflight 不采用，超出具名边界；回改旧 negative/paused
或靠重看同一 test 获胜不采用，违反冻结与独立确认纪律。仅完成更多 issue 而无科学越过也不采用。

本决策是对 0030 数据保留边界的**本方向具名扩展**，不取代 0030 其余契约，不修改 0037 的具名范围。
