# 0021 实验授权的会话内询问通道

- **日期**：2026-09-29
- **状态**：superseded by 0029

## Context

`AGENTS.md` 禁止在无显式授权时执行 GPU 租赁、大批量训练、多年度数据下载等动作，实验 workflow 另有
2026-09-25 的「不主动触发」用户决定。此前"授权"只以用户自由文本出现：代理无法确定**何时问、问什么、
授权覆盖到哪**，授权欠账也不可见——机器可读回执试点至今没有一份真实运行产物，就是因为"要不要跑、
跑哪一条"从未变成一次明确的询问。用户（2026-09-29）要求把通道固定下来：实验授权可以在
**要执行的那一刻**用 `AskUserQuestion` 向用户取得，用户也可以**预先书面**交付一个具名范围。

## Decision

1. 需要授权的实验类动作（触发实验 workflow、GPU 运行、训练/评估）在执行前用 `AskUserQuestion` 提问。
   问题必须写明：要跑什么（workflow/脚本与触发标签）、范围与预算（时间、GPU-h、字节或更新数）、
   预期产物与证据、失败 / skip / 取消时的处理。
2. 用户可以不逐次询问，而是**预先书面授权**一个具名范围（会话消息、`docs/goals/` 长文或决策记录）。
   授权文字必须含范围、预算与停止条件，并由代理记入计划 / 目标 / 运行记录；它只覆盖写明的范围。
3. 授权**不自动扩展**：不覆盖其它实验、其它数据或更高预算；`main` 合并、force push、破坏性数据操作
   **不在本通道内**，仍按 `AGENTS.md` 的原有边界逐次取得。
4. 被授权的运行仍受 R-006（先冻结 protocol）、R-028（离线禁网）与预算纪律约束；授权不豁免这些规则。
5. `skip` / `cancelled` / `queued` / `partial` / `failed` 仍然不算通过，也不产生科学结论。

## Consequences

**变容易的：** 授权有固定落点与固定格式，范围 / 预算 / 证据在动手前可见；重复实验不必逐次打断；
授权欠账（"该问没问"）变成可检查的缺失——没有授权文字就不该有运行。

**变难 / 代价：** 每次实验前多一次询问往返；预先授权的文字要写清范围与停止条件，写不清时只能退回
逐次询问；授权记录成为新的待维护事实，本轮不引入自动扫描，靠计划 / 决策 / 运行记录落盘。

**备选方案与否决理由：** "代理自行决定有界实验"被否决——预算与数据边界是用户的，不是代理的；
把授权并入 CI 标签机制被否决——标签只表达触发意图，不表达范围、预算与停止条件；维持"自由文本授权"
现状被否决——通道不明确时授权欠账不可见。
