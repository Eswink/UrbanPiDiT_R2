# 0094 — Stage C1 **不开轮**：冻结前实测推翻「最优点包含真实场」的族判别

- **日期**：2026-11-07
- **状态**：accepted
- **范围**：`training/r7_physical_constraints.py`（量纲修正 + 按名取通道）、
  `tests/test_r7_s3_physical_constraints_c1.py`、决策 0092 的状态
- **依据**：决策 0084 §6（「与已关闭的空间梯度损失不是同一族」是**开轮前置**，
  论证不成立则**不得开轮**）、决策 0092（被本 ADR 的实测部分推翻）、
  `docs/goals/s3-throughput-and-physics-campaign.md` Stage C1、
  `docs/R7_S3_SPATIAL_GRADIENT_LOSS_RESULT.md`（已关闭的对照）

## Context

**① 决策 0092 的族判别建立在一个**可检验的经验命题**上，本 ADR 把它检验了。**
0092 的论证原文是：空间梯度惩罚的最优解是**常数场**（退化），而 C1 的三项「在真实大气里
**本来就满足**」，「最优解**包含**真实场」，因此不是同一种「用平滑换技巧」的交易。
最后这句不是修辞，它断言：**约束对分析场的取值 ≤ 对模型预测的取值**。
若该不等式反向成立，C1 的下降方向就是**把预测推离真实场**——与空间梯度惩罚同一失效模式，
族判别失败，按 0084 §6 **不得开轮**。

**② 冻结前先测了剂量，发现原实现量纲不成立。**
第一版按 0092 的写法平方**绝对**违反量，把 `s^-2`、`kg²/kg²`、`K²` 直接加到归一化空间
的 MSE 上。在**本轮真实起点**（1,600-update 父）的 4 个 train batch 上实测：

| 位置 | `L_c1` | `L_mse` | 参数梯度范数比 |
| --- | ---: | ---: | ---: |
| 父 1600，case 1000 | 2.19e-06 | 9.33e-01 | 1.01e-03 |
| 父 1600，case 9000 | 9.60e-11 | 1.13e+00 | 4.10e-10 |
| 父 1600，case 17000 | 4.87e-11 | 9.25e-01 | 3.29e-10 |
| 父 1600，case 25000 | 1.27e-10 | 1.43e+00 | 2.73e-10 |

即该轴**在最需要它的起点上完全不能作用**（梯度比低至 1e-10）。若照此冻结，(a) 的
「不退化」必然成立、(b) 的「违反量下降」必然不成立——**结论会是剂量造成的假阴性**，
而不是关于物理约束的证据。这正是「估计值不得写成实测值」要防的事，只是这次防的是
「把零剂量当成零效果」。

**根因**：legacy 的 `w_wind_div = 0.1` 乘的是 `|du_dx + dv_dy|`，其中 u10/v10 的差分是
**网格索引差**、单位 m/s（实测均值 **0.331**）；C1 乘的是**球面散度**、单位 s^-1。
同一标称权重下两个量实测相差 **3.4e9 倍**。因此 legacy 的数值**不能**作为绝对剂量沿用，
只能作为相对权重。

**修正（已实现并测过）**：每项先除以一个**声明的物理尺度**再平方，使其无量纲、违反量在
该尺度上时为 `O(1)`：`DIVERGENCE_SCALE = 1e-5 s^-1`（分析场 `|div|` 的 p95 量级）、
`HUMIDITY_SCALE = 1e-3 kg/kg`（分析 q850 均值的约 1/6）、`TEMPERATURE_SCALE = 1 K`。
修正后同一批实测：父 1600 上 `L_c1/L_mse` 为 **0.52–0.89**、梯度比 **2.1–4.1**；
端点（128,528）上为 **0.11–0.29**、梯度比 **0.50–1.24**。**轴现在能作用了。**

**③ 轴能作用之后，立刻测了族判别的那条不等式。**
8 个 train batch，p1600 端点，分析场（`atmos_target`，真实场）对模型预测：

| 项 | 模型 | 分析场（真值） | 真值/模型 |
| --- | ---: | ---: | ---: |
| 散度 | 0.8286 | **8.4703** | **10.2×** |
| 比湿非负 | 0.0 | 0.0 | 两者皆零 |
| 露点 ≤ T | 9.38e-05 | 2.72e-05 | 0.29× |
| **合计** | **0.0829** | **0.8470** | **10.2×** |

**逐例无一例外**：8/8 个 case 上真值都被罚得更多（比值 6.50–15.48）。

不依赖我选的尺度常数、用**原始物理量**复核同一条结论：

| 量 | 模型 | 分析场 |
| --- | ---: | ---: |
| `mean |∇·(u,v)|` (s^-1) | 8.52e-06 | **2.51e-05** |
| `|∇·(u,v)|` p95 (s^-1) | 2.39e-05 | **7.30e-05** |
| `q850` 最小值 (kg/kg) | 2.11e-03 | 1.05e-03 |
| `q850 < 0` 的比例 | 0.0 | 0.0 |
| 露点违反均值 (K) | 1.81e-04 | 2.77e-04 |

**即：模型场比真实场更平滑。** 真实大气的逐层散度**不是**近零的，实测分析场
`mean |div| = 2.5e-05 s^-1`，而模型只有其 1/3。因此「惩罚散度」的下降方向是
**把预测推向比真实更平滑的场**——这正是空间梯度惩罚被关闭时的失效模式，
而不是 0092 假设的「推向满足约束的流形」。

**④ 比湿项在本 store 上恒为零，是一个死项。**
8 个 case、父与端点、模型与分析场：`q850` 最小值始终 **> 1e-3**，`q850 < 0` 的比例
始终 **0.0**。即 `relu(−q)²` 在这份数据上**永远返回 0**，不携带任何梯度。
它在束内占权重 0.5（三项里并列最大），实际贡献恒为 0——束的标称构成与实际构成不一致。

**⑤ 露点项方向正确但量级极小。** 真值违反均值 2.77e-04 K、模型 1.81e-04 K，
两者都远小于 1 K 的尺度，项值在 1e-4 量级，相对 MSE 可忽略。

## Decision

**1. Stage C1 按 0092 设计的形态**不开轮**。** 决策 0084 §6 的开轮前置是「论证与空间梯度
损失不是同一族」，而 0092 论证所依赖的经验命题（最优点包含真实场）在**本 store 上实测为假**：
散度项对真值的惩罚是模型的 **10.2 倍**，8/8 例一致。按 0084 §6 原文，**论证不成立则不得开轮**。
本 ADR 因此不是「本轮失败」，而是**前置检验按设计拦下了它**——这正是前置存在的意义。

**2. 不调尺度常数去「救」它。** 把 `DIVERGENCE_SCALE` 调大到让真值也免费，等价于
**用真值拟合阈值**：那会把「散度是不是约束」偷换成「多大的散度算违反」，并且判据将
由被测数据决定。0092 已把 ε 记为「先冻结的自由度、不得看了读数再调」；本 ADR 遵守该条，
**不因读数而改常数**。

**3. 保留已完成的工程修正，因为它们独立成立。** 量纲修正（`O(1)` 归一）与**按名取通道**
是任何后续物理项都需要的前提，且各自有反证测试：
- 按名取通道：store 的 17 通道序是 `t2m,u10,v10,mslp,z850,…`，而算子要的是
  `mslp,t850,q850,u850,…`；**按位置 zip 会把 `t2m` 当成 `mslp`、把 `mslp` 当成 `u850`**，
  三项全部算在错字段上却仍返回看似合理的数。冻结前发现并改为按名索引（缺失即 `KeyError`）。
- 量纲修正：见 Context ②。

**4. Stage C2 不受本 ADR 影响，但必须先过同一条前置检验。**
C2 是**导数域的目标匹配**（惩罚 `|∇·pred − ∇·target|²`），它读 target，因此**不存在**
「最优点是否包含真值」这个问题：`pred = target` 时逐项为零，最优解**就是**真值。
但 C2 的 ADR 仍须论证它与空间梯度损失不同族（0084 §6 对两轮都要求），并**在冻结前**
实测一次「真值处为零、模型处为正」——本 ADR 的方法（8 batch、原始物理量复核）可直接复用。

**5. 若未来重开 C1 或任何无目标约束束，必须满足以下全部条件，缺一不开：**
(a) 先证明该约束在**分析场上的取值 ≤ 在模型上的取值**（本 ADR Context ③ 的表格形态），
且逐例一致；(b) 每个分项在该数据上**非恒零**（本 ADR Context ④ 的反例：比湿项恒零）；
(c) 尺度常数由**分析场分布**导出并冻结，不由读数调整；(d) 分项单独可测，不得只报束合计。

## Consequences

**负面后果（代价，必须如实列出）**

1. **Stage C1 的预算（约 64 GPU-h）没有花，但也因此没有产出 C1 的科学读数。**
   登记的是「前置检验否决」而非「实验阴性」——两者不可互相冒充：本 ADR 不能声称
   「物理约束无用」，只能说「这一束在**这份数据、这个尺度**上会推离真值」。
2. **本 ADR 的实测只覆盖 65×65 多年实例（2000–2021 train / 2022 val）。**
   129×129 wide 实例、5 年清单、其它分辨率**未测**；散度是尺度相关的量，
   换网格后 `mean |div|` 会变，结论**不可外推**。
3. **只用了一个模型（p1600 端点）与一个父（1,600 updates）。**
   若某个更弱或更强的模型其散度谱不同，比值会变；n=1 模型，无区间。
4. **`DIVERGENCE_SCALE = 1e-5` 等常数是本轮选择，依据是分析场分布而非测量最优值。**
   它们只影响项的**大小**，不影响 Context ③ 那条不等式（该条用原始物理量复核过，
   与尺度常数无关），但**影响 (a) 判据的灵敏度**。
5. **比湿项恒零这一事实只在本 store 成立。** 若换到含干区/高层的数据，`q < 0` 可能出现，
   该项才会活。本 ADR 不据此断言该约束无意义，只断言它**在这份数据上不携带信息**。
6. **工程修正改动了 `training_code_sha256`。** 因此即便未来重开 C1，也不能与 Stage B
   的臂作代码身份对照——与 0092 已记录的同一条限制。
7. **0092 从 `proposed` 变为 `rejected`，但其设计内容仍然可读。** 状态变更写明原因，
   **不删除**该 ADR：它是「前置检验拦下一个设计」的留痕，删掉就等于抹掉这次拦截。

**正面后果**：在花掉约 64 GPU-h 之前，用一个 CPU-only 的实测（约 20 分钟、0 GPU-h 训练）
发现该束会推离真值，并顺带发现两个真实缺陷（按位置取通道、量纲不匹配）与一个死项（比湿恒零）。
族判别从**措辞**变成了**可检验的不等式**，而这条不等式现在是重开的前置条件。

**否决**：
- 调大 `DIVERGENCE_SCALE` 让真值免费（等于用真值拟合阈值，判据由被测数据决定）；
- 只保留露点项开一轮（它方向正确但量级 1e-4，且单独开轮会把「束」偷换成「单项」，
  与 0092 §5 的分离实验设计冲突）；
- 把本 ADR 记成「C1 阴性」（那是冒充实验结论，实际是前置否决）；
- 直接删掉 0092 或把它改成 `accepted`（抹掉拦截留痕）；
- 顺手在 C1 里加 target 读数以「让它有效」（那就变成 C2，且破坏了 C1 的无目标定义）。
