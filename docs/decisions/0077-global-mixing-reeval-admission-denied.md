- **日期**：2026-11-02
- **状态**：accepted
- **范围**：`docs/plans/0025-training-speed-observability-axis-reeval.md` §4.2 队列**第 2 条**

- **依据**：0057（队列可执行 + ADR 必须论证「不是同一族」）、

  65×65 多年 store 与 129×129 wide store 的只读实测、决策 0067/0030

## Context

**① 旧臂是什么。** H-C 轮（2026-10-15）在 **wide 129×129 实例**上跑了两臂：`global`（对全部
context token 做 N×N 全注意力）与 `local`（主干同款 `window_size=4` 窗口注意力），
二者由**同构 block 外壳**声明**同名同形状的 12 个张量**，故参数量**逐位对齐 = 444,864**。
唯一因子是**这一层的混合范围**。冻结协议：`input_windows=2360`、`usable_windows=2140`、
`updates=2400`、`batch_size=1`（= **1.12 epoch**）、监督域 `interior_32`（4,225 格）。

**② 旧臂的结论是 null，且已按预声明出口关闭。** G−L 的 `interior_32` t2m Δrmse 在五个 lead 上
**三 seed 全部不同号**（seed 均值 −0.00019 / −0.00003 / −0.00217 / +0.00186 / −0.00247 K）；
72 h 两臂 skill 三 seed 全负（G −0.1748/−0.2650/−0.1511，L −0.1745/−0.2709/−0.1506）。
预声明出口（72 h 三 seed 全正 **且** G−L 72 h 三 seed 同号为优）**两条都未满足** ⇒ 关闭 H-C 这一支。
页内 §8 明写该 null 的归因边界：「**瓶颈不是感受野**」，**且**该无差异与「额外容量」不可分。

**③ 计划 §4.2 给 R3 的排队理由，逐条核对。** 计划写的是三层：
(a)「**null**（非方向性负结果），页内明写『更强操纵/更多数据下未测』」；
(b)「+0.6 GiB，**低于** depth/width」；(c)「吃算力不吃显存；表达力型机制最贴合『数据变大』前提」。
本 ADR 逐条实测核对，结论是 **(a) 不成立、(b) 与 (c) 成立但与「不是同一族」无关**。

**④ 实测 (a) 不成立——这是本 ADR 的核心，也是本会话新勘误的直接后果。**
旧轮协议/六份回执里的 `declared_compute_gap` 写的是
`attention_length_ratio 68.0625`、`attention_ratio 57.19140625`、`layer_ratio 1.9129018382845497`，
参考块 `FLOPS_REFERENCE` 写 `tokens 1089 / padded_hw [36,36] / windows 81`。
**那套数字是 65×65 模型输入的几何**（`pad_to_patch` 65→66、patch-2 → 33×33、window-pad → 36×36，
`33²=1089`、`9²=81`），而该轮**实际训练与评分的输入是 129×129**。实测四项（详见勘误页 §1）：

| 实测 | 结果 |
| --- | --- |
| 该轮 store `state` 形状 | `(3360, 17, 129, 129)` |
| `ZarrLongRolloutDataset(train.jsonl, physical_steps=12)[0]` | `coarse_history (2,17,129,129)`、`physical_targets (12,17,129,129)` |
| 用该轮**归档 `code.zip`** 重建模型并前向 129×129 | `token_hw (65,65)` = **4225 tokens**、`forecast (1,17,129,129)` |
| 归档执行路径 8 个文件的裁剪搜索 | **0 命中**（没有 65×65 裁剪） |
| 该轮**自己的** `_analytic_flops()` 传真实 ref（tokens 4225, windows 289） | `264.0625 / 241.2768301254 / 4.5945744831` |

即实际算力差是 **SDPA ×241.28（非 ×57.19，低估 4.2188×）**、**整层 ×4.5946（非 ×1.9129，低估 2.4019×）**、
注意力长度 **×264.06（非 ×68.06）**。**因此「更强操纵下未测」这一句对旧臂不成立**：
旧臂的 global 臂**已经是在 129×129 上做全注意力**，操纵并不弱——只是它的幅度被记小了 2.4–4.2 倍。
计划 §4.2 用来排队列的那条「未测」，实测是**已测**。

**⑤ 实测：新制度下同一机制的操纵**比旧臂更弱**，与 §4.3 的直觉相反。**
这里必须**分开报两个不同的量**（正是 ④ 里旧轮把「评分盒几何」与「模型几何」混为一谈的同一类错误，
本条不得重犯）：

| 口径 | 旧臂（129×129，32°×32°） | 新制度（65×65，16°×16°） | 新/旧 |
| --- | ---: | ---: | ---: |
| **操纵强度**：局部窗 2.0° 到全域的相对步长（= 域宽 / 窗宽） | **16.00×** | **8.00×** | **0.500（弱 2×）** |
| **绝对可达范围**：全注意力能跨过的物理距离 | **32°** | **16°** | 0.500（弱 2×） |
| **序列长度/算力**：`tokens / tokens_per_window` | 4225/16 = **264.0625** | 1089/16 = **68.0625** | 0.258（弱 **3.88×**） |

**操纵强度**的诚实口径是**行 1**：局部窗口在两个实例上都是 2.0°（`window_size=4 × patch_size=2 ×
0.25°/像素`），而域宽从 32° 缩到 16°，故「从局部跳到全域」这一步的相对幅度**减半**（16× → 8×），
绝对可达范围也**减半**。行 3 的 3.88× 是**序列长度/算力**的比，**不是**操纵强度的比；
两者方向一致但**不是同一个量**，不得互相替代（旧轮正是用错这类口径才产生 ④ 的勘误）。

⇒ 结论不变且更强：**新实例上同一机制的操纵更弱（相对步长与绝对范围都弱 2×，算力规模弱 3.88×）**。
§4.2/§4.3 的「数据变大 ⇒ 表达力型机制更该重估」这一推论，在**几何上**是反的：
更多**年份**（时间样本 2,140 → 32,131 窗）不等于更大**空间范围**（32° → 16° 是**变小**）。
时间样本变多与感受野无关，而 H-C 假设的全部内容就是感受野。

**⑥ (b)(c) 成立，但它们不构成「不是同一族」。** +0.6 GiB 的低显存增量、以及「吃算力不吃显存」
属实，且新制度上并发余量充足（R2 实测每卡峰值 4.9 GiB，门槛 11.7 GiB）。但这两条是**成本与可行性**，
不是**假设身份**——0057 要求论证的是「该假设与已关闭旧臂不是同一族」，不是「跑得起」。

**⑦ 七 gate 里至少一条不过。** 「假设独立」这一 gate 要求本条假设与已关闭旧臂**不同族**；
按 ④⑤ 的实测，本轮能写的只是「同一个感受野假设，在**更小**的空间范围上再问一次」——
那是**同一族、更弱操纵**，属 AGENTS.md 明禁的「换名重开」形态（换实例不换假设，且操纵更弱）。
其余 gate（产物隔离、计算资源、数据实例、可变状态、可独立验证、多重比较）**都过**，
本条否决**只**由假设身份一条触发。

## Decision

1. **本轮不开 R3**。理由不是「不想做」或「成本高」，而是**0057 §4.4 自己的规则**
   「论证不成立则不得开轮」：按 ④⑤ 的实测，「与已关闭旧臂不是同一族」这一句**写不出来**，
   且**写得出的方向是反的**（操纵更弱）。**不消耗任何 GPU-h。**
2. **计划 §4.2 的排队理由需按本 ADR 更正**，不作废计划本身：
   - 「更强操纵下未测」这一句对 H-C **不成立**，须由勘误页替代（旧臂操纵**已强**、且比记录的强 2.4–4.2×）；
   - 「更多数据」在新制度上只增加**时间**样本，不增加**空间**范围，对感受野假设**不构成新操纵**。
   计划 0025 §4.2 表格的原文**不改写**（历史文档不静默重写），更正以本 ADR + 勘误页为准。
3. **不换名重开、不改判据、不加 seed、不扫秩/层数/窗口**。特别地，**不**用「低秩/池化全局算子」
   作为绕过——那会同时改**算力口径**与**参数量对齐**，是另一个假设，须另立 ADR 且不得引用本条的 null。
4. **队列顺序推进**：R3 记为**否决（not-admitted）**，下一轮取 §4.2 的 **R4（位置保留 H-B）**。
   0057 的 ①（已由 0058 开轮、R2 正在跑）与 ② 至此各有处置；③ ④ 未动。
5. **若用户将来要求仍要问 H-C**，唯一站得住的立项形态是：**在同一空间网格上**改变操纵强度
   （如低秩全局 vs 全 N×N），并把「算力不对齐」与「参数量对齐」分别声明——那是一条**新假设**，
   须新 ADR，且**不得**称它为「H-C 的重估」。

## Consequences

**变容易的：**
- 省掉一整轮 6 臂的 GPU 支出（照 R2 同规模实测：每臂训练 11.92 h + 五 lead 评分 0.81 h ≈ **76 GPU-h**），
  以及随之而来的 3 seed × 5 lead 的新比较与多重比较负担。
- 「感受野轴」现在有了一个**可复算**的处置依据：不是「没人试过更强的操纵」，而是
  「更强的那次已经试过、被记小了，且新实例只会更弱」。以后有人再提 H-C，可直接引用本 ADR + 勘误页。

**变难 / 代价（如实列出）：**
- **这是一次否决，不是一次证据**：本轮**没有**产生任何新读数，因此**不能**用本轮支持或反驳任何
  关于感受野的说法。R3 在队列里从此前「待重估」变成「已否决」，而**否决的依据是几何与记录**，
  不是新实验——这一点必须照此读，不得被引作「感受野已被排除」的新证据。
- **它依赖一个本会话才被发现的历史记录错误**：若勘误页的判断将来被推翻（例如证明该轮确实跑了
  65×65 输入），本 ADR 的 ④ 就失去支撑；⑤（新实例 32°→16°、相对步长 16×→8×，另有 1089 vs 4225 tokens）是**独立**于勘误的几何事实，
  单独也足以否掉「数据变大 ⇒ 更强操纵」。两条支撑**互相独立**，任一条成立即否决。
- **不动 `docs/plans/0025` 正文**意味着计划里那句「更强操纵下未测」会继续存在，
  后来者若不读本 ADR 可能再次据此排队列。这是选择「不静默重写历史文档」的代价，已在 §Decision 2 写明。
- **跨会话风险**：R2 的 seed 43 仍在跑，本 ADR 不触碰其任何执行文件（91 项 import 闭包）与冻结协议；
  `model/**`、`training/**`、`data/**`、`scripts/study_r7_s3_anchor_feedback_65x65.py` 均**零改动**。

**备选方案与否决理由：**
- **备选 A：照计划 §4.2 照开，把「操纵更弱」写进 limitations。** 否决：那等于明知操纵更弱仍以
  「重估」名义开一轮，属事后放宽准入论证；且 null 会更难解读（弱操纵的 null 不能否证假设）。
- **备选 B：改在 129×129 上跑（保住旧几何），但用多年数据。** 否决：**不存在 129×129 的多年源**
  （0056 前提二已实测；计划 0025 §8 亦禁止新增下载），且重建即新数据获取，超出本会话授权。
- **备选 C：把 R3 提到 R4 之前、先做 H-B。** 本 ADR 就是把它换成 R4，见 §Decision 4。
- **备选 D：连同 R4/R5 一起否决，直接收束队列。** 否决：R4 的关闭原因是**操纵强度缺陷**
  （`position_query` 模量 0.0074–0.0125 vs 同层投影 ~8.02，差 3 个数量级），那是一条**不同的**
  可修缺陷；它是否与新制度相关须单独核，不能由 H-C 的否决顺带判定。
