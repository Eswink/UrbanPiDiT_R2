# 0100 — Stage E3（H-C）的立项形态：0077 §5 的唯一可站立形态需要**先造一个低秩全局算子**，本轮不造

- **日期**：2026-11-08
- **状态**：proposed
- **范围**：目标长文 Stage E3「E3 H-C 只能按决策 0077 唯一允许的形态即同网格改操纵强度、
  低秩对全 N×N、算力与参数量分别声明、不得称 H-C 的重估」的**立项判定**。
  **本 ADR 不造算子、不冻协议、不跑 GPU。**
- **依据**：决策 **0077** §5（唯一可站立形态）、§4⑤（新制度下操纵更弱）；
  决策 **0057** §4.4（论证不成立则不得开轮）；`model/global_mixing_r7.py` 的只读实测

## Context

**① 目标长文给 E3 的许可是"条件式"的，不是"去做就行"。** 原文（`docs/goals/s3-throughput-and-physics-campaign.md`
Stage E）写的是：E3 只能按**决策 0077 唯一允许的形态**。而 0077 §5 把这个形态定义为：
「**在同一空间网格上**改变操纵强度（如低秩全局 vs 全 N×N），并把『算力不对齐』与
『参数量对齐』分别声明——那是一条**新假设**，须新 ADR，且**不得**称它为『H-C 的重估』」。
因此 E3 的第一步不是开轮，而是判定**该形态在本仓是否已经可执行**。

**② 实测：本仓只有两种混合模式，没有低秩全局算子。**
`model/global_mixing_r7.py:30` 的 `MIXING_MODES = (GLOBAL, LOCAL)`，即
`ContextMixLayer` 只构造 `GlobalAttentionBlock`（全 N×N）或 `WindowAttentionBlock`（窗口）。
**没有任何低秩/池化/线性注意力算子。** 所以 0077 §5 点名的「低秩全局 vs 全 N×N」
这个对照**当前不存在第二个臂**——要跑 E3 必须先**新增一个算子**，
那是 `model/**` 的架构变更，不是配置变更。

**③ 实测：已有的 global vs local 对照是**参数量逐位对齐**的，这一点 0077 记得对。**

```
ContextMixLayer(192, 6, window_size=4, mode=global)  444,864 params
ContextMixLayer(192, 6, window_size=4, mode=local)   444,864 params
参数名集合是否相同：True   （n1 / qkv / proj / n2 / ff，同序同形状）
```

这与旧 H-C 轮记录的「12 个张量同名同形状、参数量 444,864 逐位对齐」**一致**。
⇒ **如果** E3 用 `global vs local` 做对照，参数量对齐这一条**已经免费成立**，
不需要额外声明或控制。

**④ 实测：算力不对齐有多大，按新网格 65×65 复算，逐位复现 0077 的数。**
33×33 = 1,089 tokens、窗口 4×4 = 16 tokens：

| 量 | 实测 |
| --- | --- |
| local 的注意力对规模 ≈ N·w² | 1,089 × 16 = **17,424** |
| global 的注意力对规模 ≈ N·N | 1,089² = **1,185,921** |
| 比 | **68.06**（= N/w² = 1089/16，与 0077 记的 `68.0625` **逐位相同**） |

⇒ 「算力不对齐」是 **68 倍**级别的差，不是小幅差异；0077 §5 要求"分别声明"正是为此。
**这条必须进任何 E3 协议**，且**不得**用「同参数量」暗示「同成本」。

**⑤ 关键判断：E3 的两条可选路径，一条已经跑过、一条需要新架构。**

| 路径 | 是否满足 0077 §5「同网格改操纵强度、低秩对全 N×N」 | 本仓现状 |
| --- | --- | --- |
| **A. `global vs local`（已存在的两种模式）** | **只满足前半**：同网格、操纵强度不同（全域 vs 2°窗）；但**不是低秩对全 N×N**，而是**全 N×N vs 窗口** | 算子已存在（`global_mixing_r7.py`） |
| **B. 低秩全局 vs 全 N×N** | **完全满足** | **算子不存在**，须新增 `model/**` 代码 |

**A 的问题不只是措辞**：`global vs local` 正是**旧 H-C 轮做过的对照**
（`record:s3-global-mixing-result`，两臂 `global`/`local`）。用它做 E3，就是 0077
点名的**「换名重开」**形态——换实例（129×129 → 65×65）不换假设，且 0077 §4⑤ 已实测
新实例的**操纵强度更弱 2×**（相对步长 16× → 8×、绝对范围 32° → 16°）。
⇒ **路径 A 不得开轮**，与 0077 的否决理由逐条相同。

## Decision

1. **E3 本轮不立项、不开轮、0 GPU-h。** 理由不是成本，而是 0077 §5 点名的形态
   （低秩全局 vs 全 N×N）在本仓**缺少第二个臂**：`MIXING_MODES` 只有 `global`/`local`，
   没有低秩算子。**要跑 E3 必须先造算子**，那是架构变更，须自己的 ADR + 测试 + 参数量/算力声明。

2. **路径 A（`global vs local`）明确否决**，理由具名：它就是旧 H-C 轮的同一对照，
   属 0077 与 `AGENTS.md` 明禁的「换名重开」；且 0077 §4⑤ 已实测新网格上操纵更弱 2×。
   **不因「算子已经现成、最省事」而采用它。**

3. **若用户要求推进 E3，唯一可执行的立项形态**（按 0077 §5 逐条落地）：
   - **新增**一个低秩全局算子 `mode="low_rank"`（低秩投影到 r 个基再散回），
     与 `GlobalAttentionBlock` **同名同形状的 12 个张量**、参数量**逐位对齐 444,864**；
   - 对照 = `low_rank` vs `global`（**同网格 65×65**，唯一因子是**全局混合的秩**）；
   - 协议**分别声明**两件事：`parameter_alignment`（必须逐位相等，实测 444,864）
     与 `compute_misalignment`（低秩的注意力对规模 ≈ N·r vs global 的 N·N，
     按选定的 r 逐例算出，**不得**只说"更低"）；
   - **不得**称其为「H-C 的重估」（0077 §5 末句），只能称「全局混合秩的新假设」。

4. **本 ADR 只做判定，不实现算子。** 实现属下一轮，须先写 ADR，再改 `model/**`
   （会改 `model_code_sha256` ⇒ 须重做父迁移，照 0075/0083 先例），
   并在 `attempt06` 结束、其身份不再被校验之后进行。**本 ADR 0 GPU-h、零读数。**

5. **不据此宣称感受野/全局混合无效。** 0077 已明确「这是一次否决，不是一次证据」；
   本 ADR 更进一步：它连否决都不是，只是一次**关于形态可行性的判定**。

## Consequences

**负面后果（代价，必须如实列出）**

1. **E3 在本轮是"未启动"，而目标长文把它列为 Stage E 的一项。** 本 ADR 没有把它变成完成，
   只把它变成**有据可查的未启动**：缺的是一个 `model/**` 算子，不是一次实验。
2. **"先造算子再跑"意味着 E3 的成本远高于其 64 GPU-h 的预算口径。** 算子实现 + 参数量对齐
   验证 + 父迁移（改 `model_code_sha256`）+ 三 seed 两臂训练，**真实成本我没有测，故不写数字**；
   只有一点可确定：它**不会**是 64 GPU-h 量级，因为光父迁移就要重跑一遍。
3. **低秩秩数 r 是一个新的自由度，且没有先验依据。** 选 r=16 与 r=64 会给出完全不同的算力
   与表达力；本 ADR **不预设**该值，留给下一轮 ADR 论证并冻结——那将是又一个"先冻结的自由度"，
   与 0092 被 0094 否决时同类风险。
4. **参数量"逐位对齐"在低秩算子上不自动成立。** `global`/`local` 之所以对齐，
   是因为两者用**同构 block 外壳**；低秩算子若用不同的投影形状，就需要额外设计才能对齐。
   本 ADR 把"必须逐位对齐"写成要求，但**没有**证明它可达成。
5. **仍然无法回答"感受野是否重要"。** 本 ADR 只有几何与代码结构的实测，没有训练读数。

**正面后果**：目标长文点名的「0077 唯一允许的形态」现在有了**可执行的定义**（Decision 3 的四条），
并且**判定清楚了本轮缺什么**（一个算子，不是一次实验）；把 0077 的两个数
（444,864 参数对齐、68.0625 算力比）在新网格上**重新算了一遍并逐位复现**，
所以引用它们时不必只靠旧记录；明确拒绝了一条**看起来最省事但实际是换名重开**的路径（路径 A）。

**否决**：

- **用 `global vs local` 充当 E3。** 否决：与旧 H-C 同一对照、操纵更弱 2×、属换名重开。
- **把 E3 记成「已完成判定所以 Stage E 做完」。** 否决：判定不是实验；目标要的是实跑。
- **本轮顺手把低秩算子写进 `model/**`。** 否决：会改 `model_code_sha256`，使在跑的
  `attempt06` 身份失效（其协议钉着 `59340710…`）；且架构变更须自己的 ADR 与测试。
- **给低秩秩数 r 预设一个值。** 否决：那是未论证的自由度，会重演 0092→0094 的失效模式。
- **声称感受野轴已被排除或已被支持。** 否决：本 ADR 零读数。

## 未决（留给下一轮）

- 低秩算子用**投影到 r 个学习到的基**还是**固定的池化/平均基**？前者加参数（破坏对齐），
  后者不加参数但表达力受限——两者的取舍需要论证。
- 秩数 r 的取值与依据（且必须与「同参数量」这一要求同时满足，可能互相冲突）。
- 是否需要第三个臂（`local`）来把"秩"与"范围"分开——那会把单因子变成双因子，
  按 0092/0095 的纪律不能合在一轮。
