## §2 开轮判据（**先过这一条，否则不谈**）

任何候选方向在开轮前必须**实测**通过下面四项。前三项是 C1 教训的直接编码，
第四项是 C2 教训的直接编码。

### J1（方向）分析场不被罚更多

对同一批 train case、同一算子、同一尺度：

```
penalty(analysis_field)  <=  penalty(model_prediction)
```

**若为假 ⇒ 最优点不含真值 ⇒ 梯度指向远离真值 ⇒ 直接否决，不开轮。**
C1 在这一条上以 7.1–10.2× 失败。

### J2（判别力）守卫必须**能失败**

零值检查不能是「自己比自己」这种按构造恒零的形式（C2 attempt07 的死因，决策 0105）。
必须构造一个**必须为正**的反例并让它在错误实现下真的非零。

### J3（剂量）dose 必须可测且在预声明带内

```
dose = penalty(analysis_scale) / L_mse
```

- **C1 的剂量**：`1e-11 .. 2.2e-06`（对 `L_mse ~ 1`）⇒ 轴推不动参数，阴性会是剂量伪影。
- **C2 的剂量**：`0.2889 .. 0.4109` ⇒ 能推，但**太大**，与 skill 抢梯度。

⇒ 新方向的带应落在**两者之间**，且**必须在冻结前写定**，不得事后调整。
候选带：**`[1e-3, 1e-1]`**（即基础损失的 0.1%–10%）。**此值须在新 ADR 里冻结后才可用。**

### J4（族判别）必须论证与已关闭损失**不是同一族**

已关闭：空间梯度损失（最优解是**常数场**）、C1（无目标，方向反）、C2（有目标但只约束
单一派生量、剂量过大）。

论证必须能指出**最优点集合的差别**，不能只说「物理」。决策 0084 §6 要求这个论证可检验，
不是修辞。

## §3 候选方向（按「最可能过 J1」排序，**均未测量**）

### 方向 A：静力平衡（hypsometric）——**最有希望**

**算子**：层间厚度 vs 层平均温度

$$\Delta Z_{850\to500} = \frac{R}{g}\bar{T}_{850,500}\ln\frac{850}{500},
\qquad
\Delta Z_{500\to250} = \frac{R}{g}\bar{T}_{500,250}\ln\frac{500}{250}$$

物理系数（现算）：`R/g · ln(850/500) = 15.53 m/K`、`R/g · ln(500/250) = 20.29 m/K`。

**为什么可能过 J1**：大气本身**必然近似满足**静力平衡，所以分析场残差小；而垂直厚度
是模型预报的已知弱项，残差大 ⇒ 罚分析场 < 罚模型的可能性高。

**为什么比 C2 好**：它约束**通道间关系**（z 与 T 之间），不是单通道的导数。
模型不能靠「抹平某一层」来降低该项而不付出 skill 代价。

**必须先查清的**：`z*` 是位势高度（m）还是位势（m²/s²）、`t*` 是 K 还是 °C、
是否在归一化空间。**单位错就是 C1 的 `s^-2` 事故重演。**

**风险**：低层（850–500）厚度对湿度有依赖（虚温修正），忽略会在湿区产生系统偏差。

---

### 方向 B：整层散度积分近似守恒——**最便宜，但可能是 C1 变体**

**算子**：三层散度的垂直积分近似为零

$$\Big|\,\bar{D}_{850} + \bar{D}_{500} + \bar{D}_{250}\,\Big|^2$$

**为什么便宜**：`spherical_divergence` 已存在，不需要新算子，符合「不 import legacy」的要求。

**风险（必须正视）**：这是**无目标约束**，形式上与 C1 同族。J1 很可能**不通过**——
因为真实大气的散度垂直积分在有限区域内也**不为零**（有质量通量边界），
而模型的散度可能更接近零（更平滑）⇒ **分析场被罚更多**，与 C1 一模一样的死法。

**建议**：只在 A 之后测，且**预期它失败**。若 J1 通过，那本身是有意思的发现。

---

### 方向 C：热成风关系——**物理最漂亮，最可能过不了 J1**

**算子**：地转风垂直切变 vs 水平温度梯度

$$\frac{\partial \vec{u}}{\partial \ln p} = \frac{R}{f}\,\hat{k}\times\nabla T$$

**已有算子**：`spherical_scalar_gradient` + `spherical_vorticity` 均可复用。

**为什么风险最大**：
1. 真值在**低纬度 `f → 0`** 处关系失效 ⇒ 必须加纬度掩码（约 `|lat| > 15°`），
   而这个掩码本身是**人为选择**，容易被质疑为调参；
2. 只有三层，垂直切变用**差分**估计，离散误差大 ⇒ 分析场残差可能反而更大。

**建议**：预期 J1 失败。只有在 A 成功、且需要「更多物理约束」时才测。

---

### 方向 D：湿物理违反量——**最容易测，但可能没有东西可修**

**算子**：

- `q ≥ 0`（比湿非负）
- `q ≤ q_sat(T, p)`（不过饱和，Clausius–Clapeyron）

**为什么先测**：如果模型**本来就满足**，该项 ≈ 0、梯度 ≈ 0 ⇒ 无用（C1 的第一种死法）。
如果模型**大量违反**（负比湿、过饱和），那本身是一个**真缺陷**，值得单独登记。

**注意**：模型输出 `q` 在归一化空间，反归一化后才是 kg/kg。**必须用物理单位判断**。

**建议**：作为 §4 探针的一项**无条件测量**，因为成本几乎为零，且能独立回答
「模型是否产出非物理湿度」。

---

### 方向 E：谱保真度（小尺度能量）——**离群，但可能命中真问题**

**算子**：预测与目标在**每个波数带**的能量差

$$\mathcal{L}_{spec} = \sum_k w_k\left(\log E^{pred}_k - \log E^{tgt}_k\right)^2$$

**为什么值得想**：NWP 的经典失败模式是**谱阻塞**——模型输出过度平滑、小尺度能量偏少。
这条直接打这个。

**族判别（J4）的关键**：它与已关闭的**空间梯度损失**形式上接近（都作用于空间结构）。
必须论证：
- 梯度损失惩罚 `‖∇pred‖² → 0`，最优解是**常数场**，**不读目标**；
- 谱匹配**读目标的谱**，最优解是**目标的谱**，不是常数场。

⇒ 两者最优点集合不同，**不是同一族**。但这个论证必须**可检验**（例如：在 `pred = target`
时该项精确为 0，而在常数场上不为 0）。

**参考实现**：`model/r7_baselines.py:117` 已有 `torch.fft.rfft2(..., norm='ortho')` 的用法，
但那是模型内部结构，**不是损失**，需另写。
