（`high_below_low: False`）。

（`format: r7-s3-saturation-verdict-v1`，逐字记录所用规则、两个输入协议 digest、n=1 的告诫）。

**规则规定的后续**：`Δ > 0.01` ⇒ **最终 run 取 16–64 epoch**。
