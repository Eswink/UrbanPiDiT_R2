## §5 本轮的一次作废与它的修复（如实登记）

`attempt01` **作废、不参与任何读数**，产物保留不删，**10.1907 GPU-h 全额记账**：

**短抽样跨更新边界**（决策 0091）。`_BatchLoader` 把**扁平**索引流交给
`DataLoader(batch_size=4)`，而 32,131 可用窗不是 4 的整数倍 ⇒ 每个 epoch 末次抽样只有 3 个样本，
DataLoader 便跨更新边界重切。**实测**：第 **8,033** 次更新起错位、**24,099 次更新**
被喂了与登记抽样不同的样本组合、最后一次更新从未执行，最终 `StopIteration`。
**旧守卫没拦住**，因为它按调用方声明的 `len(indices)` 前进。

修法：`_draw_sizes` 显式给出每次抽样长度、`_BatchLoader` 改 `batch_sampler`、
`batch()` 按登记 draw 比对并同时比长度。`training_code_sha256 cdb89bca… → af2a5adc…`。
回归测试用 **7 窗 / batch 3 / 5 updates** 让短抽样落在运行**中间**。

`attempt02` 才是本页来源，**一次跑通**。
