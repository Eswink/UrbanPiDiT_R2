## §0 一句话

决策 0084 §6 规定 C1 的开轮前置是「论证与已关闭的空间梯度损失不是同一族，论证不成立则**不得开轮**」。
0092 的论证依赖一条**可检验的经验命题**——「三项约束在真实大气里本来就满足，故最优点包含真实场」，
即**约束对分析场的取值 ≤ 对模型预测的取值**。**冻结前把它测了：命题为假。**
散度项对分析场的惩罚是模型的 **10.2 倍**，8/8 例一致。**因此 C1 不开轮，0 GPU-h 已花。**

## §3 用**原始物理量**复核（不依赖我选的尺度常数）

尺度常数只影响项的大小，可能被质疑为「把结论调出来」。因此同一条结论用**未归一**的物理量复核：

| 量 | 模型 | 分析场 | 含义 |
| --- | ---: | ---: | --- |
| `mean |∇·(u,v)|` (s^-1) | 8.52e-06 | **2.51e-05** | 真值散度是模型的 **2.9 倍** |
| `|∇·(u,v)|` p95 (s^-1) | 2.39e-05 | **7.30e-05** | 3.1 倍 |
| `q850` 最小值 (kg/kg) | 2.11e-03 | 1.05e-03 | 两者皆正 |
| `q850 < 0` 的比例 | **0.0** | **0.0** | **比湿项恒零** |
| 露点违反均值 (K) | 1.81e-04 | 2.77e-04 | 真值违反更多，但两者都 ≪ 1 K |
| 露点违反比例 | 5.33e-04 | 5.18e-03 | 真值高一个量级 |

**结论**：真实大气的逐层散度**不是**近零的（`mean 2.5e-05 s^-1`），而模型场比真实场**更平滑**。
因此「惩罚散度」的下降方向是把预测推向**比真实更平滑**的场——这正是空间梯度惩罚被关闭时的
失效模式，**不是** 0092 假设的「推向满足约束的流形」。

## §4 顺带修掉的两个真实缺陷（冻结前发现）

### 4.1 按位置取通道会把三个项全部算在错字段上

`physical_constraint_terms` 原实现按**位置** `zip(REQUIRED_PROCESS_CHANNELS, channels)`。
但 store 的 17 通道序是 `t2m,u10,v10,mslp,z850,t850,q850,u850,v850,…`，而算子要的是
`mslp,t850,q850,u850,v850,t500,u500,v500`。实测的错配：

```
按位置 zip 会把  mslp←t2m   t850←u10   q850←v10   u850←mslp   v850←z850
                 t500←t850  u500←q850  v500←u850
```

即散度算子会拿到 `(mslp, z850)` 而不是 `(u850, v850)`，三项全部算错却仍返回看似合理的数。
**改为按名索引，缺失即 `KeyError`**；新增反证测试 `test_channels_are_matched_by_name_not_by_position`
（把同一物理场按 store 的真实 17 通道序摆放，并把 `t2m` 设成 1e6、`u10` 设成强散度，
按位置读必然爆掉，按名读必须给出与 8 通道连续摆放**逐位相同**的结果）。

### 4.2 量纲不匹配使该轴在最需要它的地方完全不能作用

第一版平方**绝对**违反量，把 `s^-2`、`kg²/kg²`、`K²` 直接加到归一化 MSE 上。实测：

| 位置 | `L_c1` | `L_mse` | 参数梯度范数比 |
| --- | ---: | ---: | ---: |
| 父 1600，case 1000 | 2.19e-06 | 9.33e-01 | 1.01e-03 |
| 父 1600，case 9000 | 9.60e-11 | 1.13e+00 | **4.10e-10** |
| 父 1600，case 17000 | 4.87e-11 | 9.25e-01 | **3.29e-10** |
| 父 1600，case 25000 | 1.27e-10 | 1.43e+00 | **2.73e-10** |

若照此冻结，(a)「不退化」必然成立、(b)「违反量下降」必然不成立 ⇒ **剂量造成的假阴性**。

**根因**：legacy 的 `w_wind_div = 0.1` 乘的是 `|du_dx + dv_dy|`，其中 u10/v10 的差分是
**网格索引差**、单位 m/s（实测均值 **0.331**）；C1 乘的是**球面散度**、单位 s^-1。
同一标称权重下实测相差 **3.4e9 倍** ⇒ legacy 的数值**不能**作绝对剂量，只能作相对权重。

**修正**：每项先除以声明的物理尺度再平方（`1e-5 s^-1` / `1e-3 kg kg^-1` / `1 K`），
使其无量纲、违反量在该尺度上时为 `O(1)`。修正后：

| 位置 | `L_c1/L_mse` | 梯度范数比 |
| --- | ---: | ---: |
| 父 1600（4 例） | 0.52–0.89 | 2.1–4.1 |
| 端点 128528（4 例） | 0.11–0.29 | 0.50–1.24 |

**轴现在能作用了**——也正因为能作用，§2 的族判别才有意义。若不做这一步，
「约束无效」会被误读成「物理无用」，而实际是「零剂量」。

| | 实验阴性 | **本页** |
| --- | --- | --- |
| 花了多少 GPU | 约 64 GPU-h | **0** |

**本页能声称**：按 0092 设计的那一束，在**这份 65×65 数据、这个尺度**上，
其下降方向与真值相反；因此按 0084 §6 不得开轮。

## §6 重开前置（缺一不开）

1. 证明该约束在**分析场**上的取值 ≤ 在**模型**上的取值，且**逐例一致**（本页 §2 的表格形态）；
2. 每个分项在该数据上**非恒零**（本页 §3 的反例：比湿项恒零，占权重 0.5 却零梯度）；
3. 尺度常数由**分析场分布**导出并**冻结**，不由读数调整；
4. 分项**单独可测**，不得只报束合计。

**C2 不受本页影响**：它读 target，`pred = target` 时逐项为零，最优解**就是**真值，
不存在 §2 那条不等式的问题。但 0084 §6 对两轮都要求族判别，故 C2 的 ADR 仍须论证不同族，
并**在冻结前**实测一次「真值处为零、模型处为正」。
