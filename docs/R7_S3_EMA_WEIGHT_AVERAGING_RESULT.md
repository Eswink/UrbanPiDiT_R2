## 1. 结论摘要

本轮只检验一个因子：**评分 checkpoint 的权重来源**。训练轨迹、前向、损失、数据、AdamW、
LR、warmup、2400 updates、K、depth、dim、物理权重、K 轴深监督、父、seed、评分域与气候态
分母全部不变；候选评分同一轨迹上 `decay=0.999` 的 plain EMA（从父权重初始化、全部 trainable
参数、每个 optimizer step 后更新、无 bias correction、无 warm-up），控制仍评 update-2400
最终优化器权重。

## 5. 公平性守卫

- **单一因子**：只有评分 checkpoint 的权重来源变化；前向、损失、数据、2400 updates、K=4、
  depth=4、dim=192、注册物理权重、K 轴深监督、LR 2e-5、warmup 10、weight_decay 1e-4、
  batch 1、clip 1、seed、评分域、气候态分母与 cohort 均不变。
- **EMA 边界反证**：`decay=1.0` 保持父权重；`decay=0.0` 精确等于最新权重；一步后
  `shadow = 0.999*parent + 0.001*w1`（证明无 bias correction/warm-up）。
- **控制与参照**：N = `record:s3-anchor-isolation-result` control 臂（pinned、注册深监督、
  锚惰性、`spatial_gradient_lambda` 不存在、评分为 `update_0002400.pt`）；A =
  `record:s3-wide-interior-dose`（pinned、未重训）。N/A 的 `boundary_rmse.csv` SHA256 与
  cohort 在 reading 阶段逐 lead 核对。
- **桥 (e)**：N−A 在 −4.787001e-6…+1.778038e-5 K（15/15），`identity_unresolved=false`。
- **比较口径的限制（必须照此读）**：候选 EMA 与 pinned 控制是**两次独立 GPU 轨迹**，
  不是同一轨迹的逐位开关；候选自己的最终优化器 checkpoint 已写出但未评分。因此配对差
  混合了权重来源与 run-to-run 差异；桥在噪声级只能说明差异很小，不能消除该混杂。
- **未读 test**：`test.jsonl` 从不读取；`test_read=false`、`scientific_claim=false`；r=0。

## 8. limitations

- 单一宽实例（129×129 输入、`interior_32` 监督、一个 ROI、17 通道、2017–2021 train / 2022 val）；
  不是多区域、多年份或全球结论。
- 候选 EMA 与 pinned 控制是两次独立 GPU 轨迹，不是同一轨迹的逐位开关；候选的最终优化器
  checkpoint 已写出但未评分，因此 72 h 配对差混合了权重来源与 run-to-run 差异。
- 控制与外部参照是 pinned 注册臂，不在本协议内重训；控制是双臂预算，候选是单臂预算
  （wall-clock 21600/43200/86400 s vs 43200/86400/115200 s；2400 updates 相同）。
- decay=0.999 是单一冻结设计系数；不扫参，decay 响应曲线未知；预声明出口失败后也不补扫。
- EMA 是 plain、无 bias correction、无 warm-up、从父权重累积；没有分离“起点包含父权重”
  与“平均窗口”的贡献，也没有 BEMA/SWA/checkpoint averaging 的对照。
- `interior_32` 不约束外圈；主评分域是 `interior_32`，full/edge 只作报告。
- 三 seed 是一致性证据，不是显著性检验；GPU 共驻；验证集 only，2023 test 仍封存。
- GPU 训练不是逐位可复现；`protocol_sha256 + code.zip SHA + 每 seed 回执 + readings.json`
  使同一协议可重放，不承诺同一结果。
