## 1. 结论摘要

- **做法**：用既有只读入口 `diagnose_r7_gain.py`（→ `training/r7_gain_oracle.py`）在三个已注册
  incumbent checkpoint 上测 K=1..8 的逐档误差；val split、1024 case/seed、`max_steps=8`、
  `step_cost=0`。**不训练、不改 `model/**`、不读 test。**
- **判据**：决策 0118 冻结的 (a)(b)(c) 与决策表，读数前已写定，未做任何调整。
- **判定（判定器输出的原始值）**：`admit-g1b`。
  - **(a) 饱和 = 真（3/3 seeds）**：k≥3 之后没有任何一步买到 1% 相对改进。
  - **(b) 病态 = 真（3/3 seeds）**：k3→4 相对**上升**超过 0.1%（实测 +0.1375% / +0.1102% / +0.2318%）。
  - **(c) 深度可用 = 假（0/3 seeds）**：k4→8 是**变差** 2.5–3.0%，不是改进。
- **按冻结表：`(b)` 真 ⇒ 允许派生 G1-B（visit-gain 阻尼）。** 本页不派生、不训练。

### 1.1 这条判定必须带上的三条读法限制（否则会被误读）

1. **k3→4 的上升很小（0.11–0.23%），而 k4→8 的衰退很大（2.5–3.0%）。** 所以本轮的**主信号**
   是「K=3 之后单调恶化」，(b) 只是它的第一个台阶。把本轮读成「残差过放大被确证」是夸大：
   0.1% 的门槛是我在 ADR 里按 `R7_65_PREDIAGNOSTIC` 的 +0.38% 定的，**它比观测值宽**，
   本轮实测落在门槛之上但幅度不大。
2. **主判据是 +6 h 目标。** `atmos_target` 是 `physical_targets[:,0]`，即 +6 h 场。因此
   「循环在 +6 h 上 K=3 最优」**不能**外推成「72 h 会变好」。72 h 轨迹**本轮未测**，记 `null`，
   且 `null` 不参与开 G1-B。
3. **样本是 2022-01 至 2022-09。** val manifest 按时间排序，1024 条上限覆盖 1–9 月，
   **缺 10–12 月**。故本轮不含四季均衡，不能称「全年」。

## 3. 与既有 K 轨迹证据的一致性

`docs/R7_65_PREDIAGNOSTIC.md` §3（4 个 val case、800 步 checkpoint、单季节）报告：
K=1 贡献全部收益、K=2 只有 1/3、**K=3/K=4 转负**、相邻修正 cosine 0.864→0.939→**0.982**、
修正范数 0.043→0.023 单调衰减。

本轮（1024 case/seed、32,132 update 的成熟 checkpoint、三 seed）给出**同向且更强**的结论：
K=3 是最优点，之后单调恶化。**两者独立**（不同 checkpoint、不同样本量、不同代码路径：
一个走 `correction_terms` 的代数分解，一个走 `per_sample_latitude_mse` 的误差序列）。
⇒ 这条形态至少有两次独立观测支撑，不是单次 artifact。

## 5. 判定与下一步（严格按决策 0118 的决策表）

判定器输出（`outputs/r7_s3_loop_depth_headroom_20261125/readings.json`）：

```

clauses : a_saturated True (3/3) | b_pathology True (3/3) | c_depth_usable False (0/3)

```

按冻结决策表第一行：`(b)` 真 ⇒ **允许派生 G1-B**（visit-gain 阻尼：A `visit_damped` vs
B `uniform_damped`，主对比 A−B）。**但「允许」不等于「应该」**，也不等于本轮已经派生：

- G1-B 仍须**自己的 brief**、冻结的 `protocol.json`、父迁移与 `state_digest` 逐位证据。
- G1-B 的成本是**估算**（2 臂 × 3 seed × 2,400 updates ≈ 11.1 GPU-h，双卡三波 ≈5.6 h 墙钟），
  未实测。
- G1-B 的增益式来自一个 **post-LN** 论文（arXiv:2607.13491），我们是 pre-LN ⇒ 外推，
  必须写进它的 limitations。

**另一种解读必须同时摆出**：本轮的**主信号**是「K=3 之后单调恶化」，其量级（k4→8 变差 2.5–3.0%）
远大于 (b) 的门槛（k3→4 上升 0.11–0.23%）。若把这些步看作「循环在推一个已经到位的解」，
那么下一轮更该问的是**「循环该改什么」**（决策 0118 里的方案 C：让循环改写 1089-token 空间表征），
而不是「如何阻尼」。**本页不在这两者之间选边**——G1-B 已被准入，C 需要自己的 ADR。
