## 五、迁移纪律

- 每片迁移独立提交，提交信息注明规则 ID（例如 `style(r7): split 18 over-long lines (R-019)`）。
- 迁移不得降低测试强度（R-009）。
- 改动 `model/` 下任何文件都会改变 `model_code_sha256`，须在提交信息中标注
  `[model-digest-change]` 并在 CHANGELOG 记录，同时确认 3 条重放 workflow 的处置方式。
- 每完成一片，更新本文件与 `CHANGELOG.md`。
