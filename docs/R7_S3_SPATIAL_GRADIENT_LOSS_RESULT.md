## 1. 结论摘要

本轮在**唯一一个因子**上检验：注册深监督损失
`L_mse = latitude_weighted_mse(..., mask=interior_32)` 的平滑偏差，是否在 2400 updates 下约束了
48/72 h 的 RMSE。候选在**每个物理 6 h 步、每个 K+1 草稿**的 per-draft 损失上加一个冻结的
first-difference 空间梯度惩罚：

```
L = L_mse + 0.1 * L_grad
L_grad = Σ_H w_h (Δ_h pred − Δ_h target)^2 + Σ_W w_w (Δ_w pred − Δ_w target)^2
         / (17 * (Σ_H w_h + Σ_W w_w))
```

选中对 = 两端都在 `interior_32` 内的相邻格点对（4160 个 H 对、4160 个 W 对）；
`w_h = mean(cos(lat) endpoints)`、`w_w = cos(lat) row`；归一化与 `latitude_weighted_mse` 的
`combined.expand_as(error)` 一致，因此 17 个相同通道的 `L_grad` 与单通道相同。λ=0.1 是**设计系数**，
不是通过/关闭阈值；不扫参；λ=0 走独立 Python 分支，`torch.equal` 与注册损失逐位相同。

## 8. limitations

- 单一宽实例（129×129 输入、`interior_32` 监督、一个 ROI、17 通道、2017–2021 train / 2022 val）；
  不是多区域、多年份或全球结论。
- 控制与外部参照是 pinned 注册臂，不在本协议内重训；F−N 是协议内配对，F/N vs A 是跨协议比较。
- λ_grad=0.1 是单一冻结设计系数；不扫参，λ 响应曲线未知；预声明出口失败后也**不允许**补扫。
- 候选从迁移父 attempt04 继续；父在无梯度惩罚的目标上训练，因此本轮价格的是“从该父出发的路线”，
  不是 from-scratch 重训。
- 惩罚作用在 `interior_32` 内 17 个通道的 normalized forward differences 上；没有按物理单位或
  通道分别加权，也没有分离“梯度项”与“总损失尺度/正则化强度”的贡献。
- `interior_32` 不约束外圈；主评分域是 `interior_32`，full/edge 只作报告。
- 三 seed 是一致性证据，不是显著性检验；GPU 共驻；验证集 only，2023 test 仍封存。
- GPU 训练不是逐位可复现；`protocol_sha256 + code.zip SHA + 每 seed 回执 + readings.json`
  使同一协议可重放，不承诺同一结果。
- 本轮中途用编排修复 `c8ec54f` 落 seed42/43；它只改调度器与测试，不改实验协议/执行文件。
  该修复的 CI 与实验 CI 分开记录，不能把编排 CI 当作实验 PASS。
