在**真实分析场**上逐通道（17 个，不取通道均值：`K`/`m·s⁻¹`/`Pa`/`m²·s⁻²`/`kg·kg⁻¹` 混在一起求均值

| 门 | 判据 | 实测 | 结论 |
| --- | --- | --- | --- |
| **P0-a** Parseval | `rfft2(norm='ortho')` 能量守恒到浮点容差 | **5.641e-16** | **过** |
| **P0-b** 接缝能量占比 | **报出，不设阈值** | **均值 0.9921，最大 0.99975**（`z250`） | 报出（见 §5 限制 1） |
| **P0-c** DCT-II 交叉校验 | 两法结论一致 | **一致**（`dct_energy == Σfield²`，17/17 通道） | **过** |
| **P0-d** J2 反证 | 假场必须使损失变差；`pred=target` 精确 0 | 真值 **0.0**（逐位）；粗化场 **549.5046**（真值为 0，故比值为无定义而非有限数） | **过** |

**P0-d 是本轮设计核心**：C2 attempt07 的守卫拿 `target` 与 `target` 比、按构造恒零，把 bug 写成物理结论
（决策 0105）。本轮构造的是**必须为正**的反例——把所有细带能量挪进粗带——它给出 549.5 而真值给出 0，
两条一起才说明守卫有判别力。

### §2.1 两个数值事实（实测，不是推测）

这两个事实决定了"精确 0"能不能成立，也就决定了 J4 的族判别能不能做：

1. **`torch.abs(z)**2` 与 `z.real**2 + z.imag**2` 不逐位相等**：随机复谱上实测 **8291/50000** 样本不同。
   用 `abs()` 建带功率，同一场与自己比会报出非零振幅失配。
2. **AMSE 式 (6) 的文字形式 `2·M·(1 − coh)` 在 `x = y` 处不为 0**：实测 **8291/50000** 非零
   （把 `coh` 上截到 1 后仍有 **4141/50000**）。这是 `coh` 舍入到略小于 1 时的灾难性相消。

**采用的有理化等价形式**：
`term2 = 2·max(P_x,P_y)·(P_x·P_y − cross²) / (P_x·P_y·(1 + coh))`。
`cross` 与 `P_x` 由**同一个表达式**算出，因此 `P_x = cross` 时分子逐位为 0 ⇒ 整项逐位为 0。
实测 **0/50000** 在 **fp64 与 fp32** 下都成立。这是 `pred = target` 精确 0 的唯一实现方式，
也是 J4「与 MSE 在 `x=y` 处同 Taylor 展开」能站住的前提。

## §3 P1 — 振幅缺口随训练量缩小 ⇒ **跳过 Stage Q**

口径：4 个 Stage B 端点（同一 treatment 清单、同一 recipe、只有 updates 不同）× 8 个 train case
（1000/5000/9000/13000/17000/21000/25000/29000）× 12 个 lead（6–72 h）× 17 通道。
每 band 的 `amp_ratio = sqrt(PSD_pred/PSD_target)` 与 `coh` 在**功率域**聚合（先求和再取比，
不平均逐 case 比值——近乎空的带否则会以同等权重贡献一个野值）。

### §3.1 主读数：细带缺口单调缩小

| 端点 | updates | 72 h skill | 细带（band 3–5）平均缺口 |
| --- | ---: | ---: | ---: |
| p0025 | 2,008 | +0.098082 | **0.32346** |
| p1000 | 8,033 | +0.159293 | **0.29482** |
| p4000 | 32,132 | +0.230544 | **0.26783** |
| p1600 | 128,528 | +0.260668 | **0.25637** |

**判据（§3.1，预声明）**：缺口缩小 ⇒ AMSE 动机弱、跳过 Q；不变或扩大 ⇒ 开路。
**判定：`monotone_decrease = true` ⇒ `verdict = skip-q`。**

### §3.2 逐带读数（6 个带 × 4 个端点）

| band | p0025 | p1000 | p4000 | p1600 | 严格单调 |
| ---: | ---: | ---: | ---: | ---: | :---: |
| 0 | +0.1191 | +0.1010 | +0.1057 | +0.0724 | **否**（p1000→p4000 反弹 +0.0047） |

**如实标注**：6 个带里 **4 个严格单调**，band 0 与 band 5 各有一次反弹。判据用的是细带均值
（band 3–5），它单调；但把整条曲线说成"全部单调"是错的，反弹已列在上表。

### §3.3 过冲样本（决策 0110 consequence 5 要求分开报）

`amp_ratio > 1` 的行为论文未讨论，必须与"振幅不足"分开计数：

| 端点 | 过冲样本 / 总样本 | 所在带 |
| --- | ---: | --- |
| p0025 | **24/576** | band0 21、band5 3 |
| p1000 | **30/576** | band0 21、band5 9 |
| p4000 | **39/576** | band0 28、band5 10、band1 1 |
| p1600 | **39/576** | band0 35、band5 3、band1 1 |

过冲集中在 **band 0（最大尺度）**且随训练量增加（21 → 35），即最粗尺度上模型逐渐开始**高估**振幅，
而细尺度仍严重不足。这与"只压低振幅"的单一叙事不符，必须保留。

### §3.4 amp_ratio 与 coherence 的接近程度（论文式 (2) 的预测）

| 端点 | `max|amp − coh|` | `mean|amp − coh|` |
| --- | ---: | ---: |
| p0025 | 0.2118 | 0.0557 |
| p1000 | 0.2193 | 0.0543 |
| p4000 | 0.2197 | 0.0558 |
| p1600 | 0.1849 | 0.0450 |

**`amp_ratio` 与 `coh` 在每个带每个端点上都很接近**（均值差 0.045–0.056），与
arXiv:2501.19374v2 式 (2) 的解析预测 **`sqrt(PSD_x/PSD_y) ≈ coh`** 相容。这**支持**该论文的机制描述，
但**同时**说明在本模型上缺口随训练缩小——两者不矛盾：解析式描述"最优解的性质"，
而我们的缺口是**在最优解仍远离真值时**的欠训练成分占主导。这一条是 §3.1 判 `skip-q` 的直接依据。

## §4 P2 — J1 方向门（**三个方向全部不通过**）

口径：**全部 8 个 train case**（1000/5000/9000/13000/17000/21000/25000/29000）、同一算子、同一尺度常数；
模型侧 = p1600 端点（128,528 updates）的 +72 h 预报，真值侧 = 该 case 的 +72 h 分析场。
**两侧同函数、同单位**（C1 的比较设计）。J1 的判据是「**逐例一致**」，所以判定读的是
`passes_j1_all_cases`，不是 pool 后的均值。

**先核单位（这一步救了一个会伪造结论的 bug）**：

| 检查 | 实测 | 结论 |
| --- | --- | --- |
| `z*` 单位 | 声明 `m**2 s**-2`，`z850` 读 **14649.5** ⇒ `/g` = **1493.8 m** | 是**位势**，不是位势高度 |
| `t*` 单位 | `t850` mean **274.50** | 是 **Kelvin**，不是摄氏度 |
| `state` 是否物理量 | 归一化在**读取时**施加（store attr 原文） | 是物理量；**再反归一化就是二次缩放** |

因此 `z` 必须 `/g` 才是位势高度。**静力残差还错过一次符号**：厚度是 `z_upper − z_lower`
（上升得到的高度），写成 `z_lower − z_upper` 会得到 −4110 m 对 +4082 m 的期望，
RMS 残差从物理的 **36.6 m** 膨胀到 **8193 m**（224×），会把"分析场严重违反静力平衡"写成一个发现。

### §4.1 逐例读数（**单 case 结论被 8 case 推翻**）

| 方向 | pooled analysis | pooled model | 方向反的 case 数 | 逐例一致 | J1 |
| --- | ---: | ---: | :---: | :---: | :---: |
| **A 静力平衡** | 385.78 m² | 194.17 m² | **6/8** | 否 | **不过** |
| **B 整层散度** | 1.7761e-09 s⁻² | 2.7122e-09 s⁻² | **2/8** | 否 | **不过** |
| **D 湿物理** | 1.1428e-11 (kg/kg)² | 2.9184e-11 (kg/kg)² | **5/8** | 否 | **不过** |

逐 case 的 `analysis/model` 比值：

| case | A 静力 | B 散度 | D 湿物理 |
| ---: | ---: | ---: | ---: |
| 1000 | **3.413** | 0.804 | 0.367 |
| 5000 | 0.684 | **1.446** | null（model=0 ⇒ 比值无界） |
| 9000 | **1.010** | 0.404 | null（双方皆 0） |
| 13000 | **4.671** | 0.824 | null |
| 17000 | **1.508** | 0.847 | null |
| 21000 | 0.959 | **1.160** | null |
| 25000 | **2.210** | 0.333 | null |
| 29000 | **3.589** | 0.365 | null |

**D 只有 case 1000 给出有限比值**，其余 7 个 case 的 model penalty 为 0（比值无界）或双方皆 0。
一个 8 例里 7 例无定义的项**不能承担方向判定**，即使它的 pooled 均值看起来"过"。

**这一节是本轮最重要的更正**：先只跑 case 1000 时，A 得 3.41×（"方向反，不过"）、B 得 0.804（"过"）、
D 得 0.367（"过"），看起来是"一个不过、两个过"。**扩到 8 个 case 后三个方向全部不过**：
A 的比值在 0.684–4.671 之间摆动、B 与 D 也都有反向 case。单 case 的 3.41× 是**偏高的抽样**，
不是稳健效应。任何基于单 case 的方向判定都会被这一次扩样推翻。

### §4.2 D 方向的惰性分项

`D_negative_only`（`q ≥ 0`）在**两侧所有 case 上都精确 0.0**：C1 已实测该分项是死项
（0.0 对 0.0、却带权重 0.5），本轮 8/8 复现。D 的非零全部来自**过饱和**分项。
且它在 4 个 case 上两侧同时为 0，比值无定义 —— 一个大部分样本都无定义的项不能承担方向判定。

### §4.3 dose 未验证 ⇒ 即便方向门有通过的方向也不能开轮

`J3` 要求 `dose = penalty/L_mse ∈ [1e-3, 1e-1]`，而 `L_mse` 是已注册归一化空间损失，
本轮**没有**为该批 case 重算它。探针把 `dose` 报为 **null** 而不是猜一个分母——
猜一个会让 J3 变成不可证伪。⇒ 三个方向的 `open_this_direction` 全为 `false`。

## §5 限制（如实列，全部是本轮实测）

1. **周期接缝占比 0.9921 均值 / 0.99975 最大**。区域 patch 不是周期的，`rfft2` 的延拓注入的不连续
   远大于内部步长。**没有设阈值**（决策 0110 明令：看到数字后选阈值就是拟合参数），
   但这条意味着**任何基于该分解的绝对数值都带一个未量化的偏差**，只能用作**相对**比较（端点之间、带之间）。
2. **单 case（1000）、单 seed（41）、单实例、单分辨率**。P2 只测了一个 case；P1 覆盖 8 case 但都是同一 seed 的端点，
   端点间差异**含未量化的运行间方差**，不是显著性结论。
3. **band 边界是选择**（0/1/2/4/8/16/角点 Nyquist）。已冻结在代码中、未扫描，但换一组边界结论是否稳定**未测**。
4. **DCT 交叉校验不能排除"网格分辨率驱动结论"**：两法共享同一张 65×65。
5. **P1 的判据是趋势方向，不是效应量**。0.3235 → 0.2564 是 20.7% 的相对下降，
   但"足够小到可以跳过 Q"是一个**预声明的规则**，不是统计检验。
6. **单 case 的方向判定会被扩样推翻，本轮实测到了。** 只跑 case 1000 时 A=3.41×、B=0.804、D=0.367，
   读起来像"一个不过、两个过"；扩到 8 个 case 后 A 的比值在 0.684–4.671 之间摆动，
   三个方向全部因"逐例不一致"而不过。**任何只报一个 case 的 J1 结论都不可信**，
   这也是 C1 用 8 例、C2 用 15 个 lead×seed 的原因。
7. **三个新探针在提交 `caaf39a` 时通过 CI 却是骨架**——测试覆盖的是合成路径，
   真实数据路径当时不存在。这条本身是流程教训：**CI 绿不等于测量成立**。

## §6 判定

| 项 | 判定 | 依据 |
| --- | --- | --- |
| **P0 分解合法性** | **通过** | §2 四门全过 |
| **P1 缺口趋势** | **`skip-q`** | §3.1 细带缺口单调缩小 |
| **P2 方向门** | **三个方向全部不过（A 6/8、B 2/8、D 5/8 例方向上反）；且 dose 未验证 ⇒ 0 个方向可开轮** | §4 |
| **Stage Q** | **不启动** | P1 判 `skip-q`（§3.1 预声明规则） |
| **Stage R** | **不启动** | plan 0030 §3.3 的前置是"P1 证实 `amp_ratio ≈ coh`"；§3.4 显示接近，但 R 的出口（五 lead skill 不劣化）需要 GPU 评估，且 Q 已跳过，本轮不开 |

**为什么这不是"物理信息没用"**：本轮实测的是**探针是否成立**，不是训练臂的效果。
`skip-q` 只说明"在这 4 个端点的训练轨迹上，振幅缺口是欠训练成分占主导"，
**不构成**"AMSE-analogue 在任何预算下无效"的证据——适用域明确限制在这 4 个端点。
`skip-q` 的**代价**是正面的：它避免了约 12 GPU-h 的一轮 Q，而 Q 的预声明出口
（72 h t2m skill 三 seed 配对差全 ≥ 0）在原设计下大概率给出一个小幅负值——与 C2 的 −0.0138 同类。
